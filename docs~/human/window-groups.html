Create

管理WindowでGroupを作る

  1. ee4v / Window / Window Groupsを開きます。
  2. 左下の新規グループを選びます。
  3. 左の一覧でGroupを選び、名前を編集します。入力欄からfocusが外れた時点で保存します。

同名Groupがある場合は連番を付けます。削除はGroupの右click menuから行います。

Membership

開いているWindowの種類を登録する

右側には現在開いているWindowの種類を表示します。先頭のtoggleで選択中Groupへの所属を追加・解除し、表示で対象Windowを前面へ移します。

  • 同じ種類のWindowが複数開いている場合は、すべて同じGroupとして扱います。
  • 1種類のWindowを複数Groupへ所属させられます。
  • 通常memberとして所属できるGroupは1つだけです。

Follower

起点にせず、ほかのWindowへ追従させる

Followerは通常memberからの同期には追従しますが、自分へのfocusから同期を開始しません。たとえばAとBが通常member、CがFollowerの場合、AまたはBへfocusすると3つとも前面へ移り、CへfocusしてもAとBは移動しません。

すでに別Groupへ通常所属しているWindowを追加すると、追加先ではFollowerになります。

Focus behavior

Groupの外から入ったときだけ同期する

  • Group外から登録済みWindowへfocusが移ったときに同期します。
  • ほかの登録Windowを順に前面へ移し、最初に選んだWindowへ最後にfocusを戻します。
  • 同じGroup内で起きたfocus移動では再同期しません。
  • 登録Windowが1つだけの場合は追加のfocus操作を行いません。

Persistence

閉じたWindowの割り当ても保持する

Group設定は利用者ごとのEditorPrefsに保存します。Windowを閉じても割り当ては残り、次回同じ種類を開いた時点で自動的にGroupへ復帰します。

通常所属を別Groupへ移す場合は、元Groupで先にFollowerを有効にしてから、移動先のFollowerを無効にします。別Groupの設定を暗黙には変更しません。
