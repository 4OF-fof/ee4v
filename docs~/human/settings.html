Generated assets

生成Assetの共通rootを決める

Preferencesの「生成アセットのルートフォルダー名」は全Projectで使う共通名で、既定値は!ee4vAssetです。Project Settingsの「このプロジェクトで上書き」を有効にした場合だけ、Project専用のroot名を使用します。

生成物root以下の保存先
新規SceneScene
新規表情ClipAnimation/Facial
Face Expression適用AssetAnimation/FacialSet/<Avatar名>
PhysBone Collider PrefabAvatar/PhysBoneCollider/<Avatar名>

既存Assetは移動しません: root名を変えた場合、新しく作成するAssetから新しい保存先を使用します。

Asset Manager

外部Sourceのpathと同期方法を設定する

PreferencesではEagle library、Eagleへの取り込み先、ee4vの管理Folderを設定します。session開始時にEagleまたはee4vを自動同期するか、Import時に取り込み先FolderへItem thumbnailを初期iconとして使うかも設定できます。

Asset Manager画面内にはpath設定を置きません。

Face Expression

BlendShapeの解析と共通dataを設定する

  • 「BlendShapeの区切り文字」でheader判定に使う文字を登録します。既定値は-、─、=、*です。リスト末尾の追加行で項目を増やし、各行の削除ボタンでその項目を除去します。
  • 「FBX別BlendShapeプリセット」から保存済みPresetを確認し、保存FolderをExplorerで開けます。
  • 「ee4v 共通データの保存先」はFBX別PresetなどProjectをまたいで使うdataのrootです。
  • Gesture Assignment Settingsの「プレビューアイコンを無効化」は同じUser設定を変更します。

Play Mode

Project単位で除去componentを選ぶ

Project Settingsの「Play ModeのNDMF処理」から、Apply on Play時にbuild対象Avatarから除去するcomponent型を選びます。詳細はPlay Mode Component Suppressionを参照してください。
