Hierarchy Style

GameObjectに背景色とiconを付ける

  1. Hierarchyで対象GameObjectへpointerを合わせます。
  2. Altを押して編集Popupを開きます。
  3. 背景色またはProject内Textureのiconを設定します。

背景色は対象から親へ向かって設定を探し、最初に見つかった色を使用します。子へ階層のまとまりを伝えられます。iconは設定したGameObjectだけに表示し、子へ継承しません。

iconの変更と解除はHierarchy上の表示に適用します。Sceneへ保存されたGameObjectのiconは自動的に消去しません。

Hidden Objects

作業中に不要なObjectをHierarchyから隠す

Hidden ObjectsはGameObjectをHierarchyから非表示にし、Scene単位のtreeから確認・再表示する機能です。HierarchyのScene見出しにある非表示iconから対象Sceneの一覧を開けます。幅の狭いドックでは検索欄とScene選択を上下に分け、下部の選択操作と再表示ボタンも画面内に収まる配置へ切り替えます。ボタン部分の左右余白を揃え、選択ボタンを均等幅にします。空状態の説明も幅に合わせて折り返します。

非表示にすると、元のactive stateとtagを記録したうえでObjectを非active化し、EditorOnlytagとHideInHierarchyを設定します。非表示操作と再表示操作はUnityのUndoに対応します。

一覧ではSceneとGameObjectをtree表示し、検索や対象の再表示を行えます。設定で除外したSceneとGameObject、その子孫は一覧へ含めません。

Restore

非表示前の状態へ戻す

再表示時はHideInHierarchyを外し、保存していたtagとactive stateを復元します。保存したtagが現在のTag Managerに存在しない場合はUntaggedを設定します。

非表示状態はEditor再起動、script再読み込み、Sceneの開き直し後にも再適用します。復元が完了したObjectの記録は保存先から削除します。

Sceneの変更状態: 非永続のHideInHierarchyだけを再適用できる場合は、GameObject、Prefab instance、Sceneをdirtyにしません。

Scene Switcher

Scene見出しからSceneを切り替える

HierarchyのScene見出しからSceneを検索し、現在のSceneとの置換、追加、または新規作成を行います。新しいSceneは共通Asset root配下のSceneへ保存します。

Hierarchy guides

親子関係と区切りを見やすくする

Depth Indicator

GameObjectの親子関係をguide線で描画します。HideInHierarchyの対象は階層計算から除きます。

Hierarchy Decoration

---で始まる空GameObjectを区切り線として描画します。

区切りObjectはGameObject / HierarchyDecoration / divから作成できます。
