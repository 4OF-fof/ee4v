VRChat editor extensions

制作の流れを、Unityの中で整える。

ee4vは、アセット整理、表情作成、PhysBone Collider設定、ProjectとHierarchyの操作をまとめたUnity Editor拡張です。

Start

まず確認する3か所

機能のWindowとMCP serverはUnity上部のee4vメニュー、利用者ごとの設定はPreferences、Project共通の設定はProject Settingsにまとまっています。

  1. Windowを開く Unity上部のee4v / ee4vから統合ウィンドウを開きます。単独機能はee4v / Windowで選びます。
  2. 利用者設定を確認 Preferences / 4OF / ee4vで、言語やAssetManagerの保存元を設定します。
  3. Project設定を確認 Project Settings / 4OF / ee4vで、生成先やPlay Mode向け処理を設定します。

Assets

購入・保管・取り込みを一続きに

AssetManagerはItem、File、Tag、CollectionとUnity Projectへの取り込み状態を管理します。Eagleとee4vの保存先を同期できます。

ee4v MCP

ee4v / MCP / Log Connection Information

CodexからAvatar監査、表情Clip、FacialSet、PhysBone Collider、衣装Toggle、Asset Managerをドメイン単位で操作します。

接続方法と安全な使い方

Asset Manager

ee4v / Window / Asset Manager / Library

単独版は検索・一覧・情報の3ペインです。ee4vウィンドウもAssetManagerでの素材選択から始めます。分割Windowは従来のOpen Allから開けます。

  • Itemを名前、説明、Tagから探す
  • Import済みItem、未所属File、Archive、Collectionを切り替える
  • ZIPやUnityPackageの内容を確認して取り込む
  • Item TargetとFileごとの依存先を設定する

Asset Managerの詳しい使い方

ee4v

ee4v / ee4v

AssetManagerで素材を選択し、Variantを作成してそのまま改変を始めます。見た目をPreviewで調整します。表情とアニメーション付き表情は既存のFace Expression画面を1カテゴリで操作できます。

Asset Protection

AssetManagerから取り込んだAssetはGUIDで追跡され、直接編集しにくい状態になります。Project内で移動しても保護は続きます。

  • BlendTree、Animation Clip、Animator Controllerの編集を抑止
  • 保護対象PrefabのPrefab Modeに警告を表示
  • PrefabやMaterialはVariant、その他は複製してから編集

保護対象と編集方法を確認

BOOTHとEagle

同梱のBOOTH userscriptはlibrary、gifts、商品ページからEagle連携を呼び出します。未取り込みのdownloadは単品または表示中の一覧から順に取り込めます。

BOOTHとEagleの連携を確認

同期設定

Preferences / 4OF / ee4v

Eagle library、Eagleへの取り込み先、ee4vの管理フォルダーを設定します。AssetManagerの再読み込み操作ではEagleとee4vを順に同期します。

設定項目と保存先を確認

編集するとき: 保護されたAssetそのものを変更せず、Unity標準機能でVariantまたは複製を作成してください。Asset Protectionは編集用Assetを自動作成しません。

Avatar

表情とColliderを見ながら調整

Face Expression

ee4v / Window / Avatar / Face Expression / Editor

VRChatアバター向けの静止表情と表情Animation Clipを作成します。表情ポーズを順番に連結し、ポーズ間の遷移時間を調整できます。

  • Expression GroupsとBlendShape Presetsは同じmenu内
  • 標準hand gestureへの割り当てはGesture Assignmentから設定
  • 表情libraryのrootは共通Asset root配下のAnimation/Facial

表情作成とGesture割り当てを確認

Gesture Assignment

ee4v / Window / Avatar / Gesture Assignment / Assignments

左右の標準hand gestureへ表情Clipを割り当てます。追加設定は同menuのSettingsから開きます。

Gesture Assignmentの詳細

PhysBone Collider Setup

ee4v / Window / Avatar / PhysBone Collider Setup

AvatarのArmatureからcapsule形Collider候補を作り、Previewしながら位置、半径、長さ、追従bone、PhysBoneへの割り当てを調整します。

  • 配置密度は軽量、通常、フルの3種類
  • 生成物はAvatar直下の1 Prefabにまとめる
  • 適用にはVRChat SDKとModular Avatarが必要

検出・調整・適用の流れ

Play Mode Component Suppression

Project Settings / 4OF / ee4v

NDMFのApply on Play時だけ、指定したcomponent型をbuild対象Avatarから除きます。Scene上の元Avatarと通常のbuild・uploadには影響しません。

対象と制約を確認

Editor

ProjectとHierarchyを読みやすく

Project Style

Project WindowのFolderに背景色とアイコンを設定します。Altを押しながらFolderを指すと編集Popupが開きます。複数選択中なら同じ変更をまとめて適用できます。

Project Styleの詳細

Project Tabs

2列表示のProject WindowへFolder tab、検索文字列、移動履歴を追加します。固定tabはUnityのProject Favoritesと同期します。1列表示ではtabを表示しません。

Project Tabsの詳細

Hierarchy Style

GameObjectに背景色とアイコンを設定します。Altを押しながらGameObjectを指すと編集Popupが開きます。背景色は親から子へ継承され、アイコンは設定した対象だけに表示されます。

Hierarchy Styleの詳細

Hidden Objects

GameObjectをHierarchyから隠し、Scene単位の一覧から戻せます。再表示時は非表示前のactive stateとtagを復元します。

Hidden Objectsの詳細

Scene SwitcherとHierarchy補助

Scene見出しからSceneの検索、置換、追加、作成を行えます。親子関係のguide線と、---で始まる空GameObjectの区切り表示も追加されます。

Hierarchy補助の詳細

Window Groups

ee4v / Window / Window Groups

一緒に使うEditorWindowをGroupへ登録し、1つへfocusしたときにまとめて前面へ移します。Followerは他Windowからの同期にだけ追従します。

Group作成とFollowerの使い方

Settings & notes

使う前に知っておくこと

対応Unity

現在の対象はUnity 2022.3です。Unity 6対応済みであることは示していません。

Modular Avatar / NDMF

PackageはModular Avatar 1.18.2以上2.0未満、NDMF 1.8.0以上2.0未満を依存範囲としています。

保存先

生成Assetの共通rootはProject Settings、AssetManagerの外部pathと言語はPreferencesから変更します。
