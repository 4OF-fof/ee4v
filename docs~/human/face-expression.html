Face Expression Editorを開くとExpression Groupsも同時に開きます。表情編集とGroup絞り込みを並べて使えます。表情Clipを選ぶと内容を自動検証し、問題がある場合だけbinding、keyframe、値、対象外curve、Object Reference Curve、Animation Eventの内容を編集画面に表示します。

Expression library

Folderと表情Clipを同じ場所で管理する

Clipを選択していない間、編集領域には現在のFolder直下のFolderと表情Clipを3列のカードで表示します。表情Clipの入力欄は右側の表情ライブラリ見出しのすぐ下にあります。library rootは共通Asset root配下のAnimation/Facialです。

  1. Avatar欄へAvatar PrefabまたはScene上のPrefab instanceを設定します。
  2. Folderカードで保存先を移動します。先頭の「＋」カードは現在のFolderを既定の保存先として新しい表情Clipを作ります。
  3. 表情カードを選び、編集を開始します。元Clipを残したい場合は右clickのコピーして編集を使います。

戻るbuttonは、編集中ならClip選択を解除し、subfolder内なら親Folderへ戻ります。選択中Clipが削除された場合も自動的にlibraryへ戻ります。

BlendShape

使用する値だけをClipへ保存する

既定では名前がBodyのSkinnedMeshRendererを表示します。各行のsliderと数値欄は0～100で連動し、使用checkを有効にしたBlendShapeだけを選択中の表情ポーズとしてAnimationClipへ保存します。ポーズが1件なら従来どおりの静止表情です。

  • 表情シーケンスのポーズカードには、割り当て画面と同じ正方形に近い顔Previewが表示されます。カードを選ぶと、そのローカルポーズだけをBlendShape一覧で編集できます。
  • 「＋ ポーズ」は選択中の表情を複製して直後へ追加します。最初のポーズでは、先にBlendShapeを1つ以上編集します。
  • ポーズ間の「＋」は、その位置へ新しいポーズを挿入します。選択中カードの左右矢印では、表情と参照Clipを一緒に1つ前または後ろへ移動できます。
  • 顔Previewを右clickして「ポーズ名を変更…」を選ぶと、カード下端のClip欄が名前欄へ切り替わり、任意の名前を付けられます。空欄で確定するか「ポーズ名を既定に戻す」を選ぶと「ポーズ N」へ戻ります。
  • 各ポーズ下端のClip欄へ既存の表情Clipを選択またはdropすると、その先頭frameをポーズへ割り当てます。割り当て中はBlendShapeを編集できません。Clipを外すと現在の表情を保ったまま編集可能になります。
  • ポーズ間の秒数を変更すると後続ポーズがまとめて移動します。ポーズを削除すると空いた時間を詰めて前後を連結します。
  • 再生buttonと再生バーは動きの確認専用です。再生位置を移動してもポーズやkeyは増えません。
  • 既存の複数key Clipは、全BlendShapeのkey時刻をポーズ列として読み込みます。
  • 使用checkを外すと、そのBlendShapeのcurve全体を削除します。LoopはAnimationClipへ保存されます。
  • 使用checkを縦方向へdragすると、通過した行を最初に切り替えた状態へまとめて変更します。
  • 左右版は通常版の下へL、Rの子行として表示し、それぞれ個別に編集します。
  • クリップ内のみでは、選択中Clipに保存されているBlendShapeとheaderだけを表示します。
  • 複数meshではメッシュ名 / BlendShape名で同名Shapeを区別します。

Clipの切り替え: 切り替え前の編集値を、切り替え後のClipへ書き込むことはありません。

Groups & presets

BlendShapeのまとまりを整理する

Expression Groups

区切り文字で囲まれたBlendShape名をheaderとして、そのheaderから次のheaderまでをGroupにします。Groupを選ぶとEditorの一覧が連動して絞り込まれます。同名Groupが複数meshにある場合は一つにまとめます。

「メッシュ追加」からAvatar内の別SkinnedMeshRendererを追加できます。追加meshはmesh名のGroupとしても表示され、選ぶとそのmeshの全BlendShapeを表示します。

BlendShape Presets

BlendShape Presetsでは、FBXごとに役割名、左右、口形状、見た目の部位を対応付けます。アバター内にBlendShapeを持つFBXが複数ある場合は「FBX切替」で対象を選べます。同じ役割の通常Shapeを親行、左・右Shapeを子行としてEditorへ表示します。役割カードやBlendShapeをdragして統合・移動でき、自動分類で現在の命名とAvatar Descriptorから分類案を作り直せます。見た目の部位を「自動」にすると従来の判定を使い、胸や腰・胴を選ぶと見た目タブの該当部位に表示します。見た目グループ名があるShapeは部位内で同じグループにまとめます。保存済みの自動生成プリセットはee4v MCPから取得して、役割名、左右、口形状、見た目の部位・グループ名をShapeごとに整えることもできます。

header判定に使う文字はPreferences / 4OF / ee4vの「BlendShapeの区切り文字」で変更できます。既定値は-、─、=、*です。

Gesture assignment

左右の組み合わせ64通りへ割り当てる

Gesture Assignmentsは左手を行、右手を列にした8×8の表です。各cellは表情Clipの入力欄とAvatar表情のthumbnailを兼ね、選択またはdrag & dropで割り当てます。

  • Settings Windowでmenu表示名、まばたき、口の動きの固定を編集します。
  • 同じ左手の行、または同じ右手の列を同期できます。
  • Extra（メニュー限定）にはgestureを使わない表情を追加できます。
  • menu表示名が空の場合は表情Clip名を使います。

まばたきを有効にした表情では生成時に瞬きcurveを作ります。口固定を有効にするとVisemeを含む口の値を表情側へ固定し、無効にするとVRChatのlip syncを適用します。

Apply

Modular Avatar経由で合成する

アバターに適用を実行すると、Avatar直下の<Avatar名>_FacialSetへMA Merge Animator、MA Parameters、MA Menu Installerを構成します。生成Prefabと関連Assetは共通Asset rootのAnimation/FacialSet/<Avatar名>へ保存します。

現在の生成形式だけを更新します。旧方式のメニューレイヤー、口変形キャンセラー、生成AssetやメニューObjectは自動移行・除去しないため、残っている場合は手動で整理してから適用してください。

  • Avatar DescriptorのFX Controller、Expression Parameters、Expressions Menuは直接変更しません。
  • Scene上のAvatarと編集可能なPrefab Assetへ適用できます。Model Prefabは直接変更しません。
  • 元の表情Clipは変更せず、複数keyのcurveとLoop設定を生成Clipへ引き継ぎます。
  • Expression MenuはFacialSetをrootとして生成し、8項目を超える場合はNext submenuへ分割します。

必要なPackage: Clipの編集とpreviewはVRChat SDKがない環境でも利用できます。Avatarへの適用にはModular Avatarが必要です。
