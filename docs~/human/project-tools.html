Project Style

Folderに背景色とiconを付ける

  1. Project Windowで対象Folderへpointerを合わせます。
  2. Altを押して編集Popupを開きます。
  3. 背景色またはProject内Textureのiconを設定します。

対象Folderが複数選択に含まれている場合は、選択中のFolderへ同じ変更をまとめて適用します。背景色だけを設定したFolderにはUnity組み込みFolder iconを表示します。

Asset ManagerはImport時に、iconが未設定の取り込み先FolderへItem thumbnailを初期iconとして設定できます。その後は通常のProject Styleとして変更または解除できます。

Project Tabs

Folderと検索状態をtabで切り替える

Project Windowのtoolbarへtabを追加し、tabごとにFolder、検索文字列、最大50件の移動履歴を保持します。toolbarの追加buttonで作るtabはAssetsを初期位置として開きます。

  • tabごとに戻る・進む履歴を持ちます。
  • tabをdragして並べ替えられます。
  • 最後のtabを閉じた場合は、既定のAssets tabを1つ作ります。
  • 複数のProject Windowを開いている場合、選択中tabはWindowごとに保持します。

2列表示のみ: Project Tabsは2列表示のProject Windowで有効です。1列表示では非表示になり、現在位置の追跡とFolder移動も行いません。2列へ戻すと自動的に再開します。

Pinned tabs

固定tabはProject Favoritesと同期する

tabを固定するとUnityのProject Favoritesと同期します。固定時は履歴を現在位置の1件へ縮め、戻る・進む操作は無効になります。

固定tabから別Folderへ移動しようとした場合は通常tabを追加し、固定tabの位置を維持します。

Folder Content Overlay

Folderの中身をiconで把握する

Folder Content Overlayは、ProjectのFolderへ配下の代表的なAsset iconを重ねて表示します。Project Styleでcustom iconを設定した項目では、重ね表示を抑制して指定iconを優先します。

Persistence

設定は利用者ごとに保持する

内容保存先
Folderの色、icon、最近使ったiconUserSettings/ee4v.item-styles.asset
tab、履歴、固定状態UserSettings/ee4v.project-tabs.asset

Project Windowの復元時は、Unity側で開いているFolderと一致する保存済みtabを選びます。検索文字列だけが違う場合も同じFolderのtabを再利用します。
