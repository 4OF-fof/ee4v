Purpose

Play Modeだけから不要なcomponentを外す

指定したcomponent型をNDMFのPlay Mode用build対象Avatarから除去します。Scene上の元Avatarは変更せず、通常のAvatar buildとuploadにも影響しません。

Setup

Project Settingsで型を選ぶ

  1. Project Settings / 4OF / ee4vを開きます。
  2. 「Play ModeのNDMF処理」で対象欄を開きます。
  3. 検索可能な一覧から除去する具象MonoBehaviour型を選びます。

一覧はAddComponentMenuのpathと表示名を使用し、属性を持たない型はScriptsへまとめます。

Behavior

ほかのNDMF Pluginより前に除去する

除去はNDMFのFirstChance phaseで実行します。非activeなGameObjectを含むAvatar階層から、選択した型と完全一致するcomponentをすべて除去します。

特定のPluginやcomponent型専用の処理はありません。AAOのTrace And Optimizeも選択できますが、AAOへの参照や専用処理は持ちません。

Limits

実行条件を確認する

  • NDMFのApply on Playが無効な場合は実行しません。
  • 派生型をまとめて除去せず、選択した型と完全一致するcomponentだけを対象にします。
  • 対象Packageが一時的に未導入でも型名の設定を保持し、再導入後に再び有効になります。
  • Avatarごとの設定componentは使用しません。
