Pages

library、gifts、商品ページに対応

同梱のExternal~/Scriptcat/B2E.user.jsは、BOOTHのlibrary、gifts、商品ページでEagle連携bridgeを呼び出します。downloadごとに現在の取り込み状態を表示します。

Single import

未取り込みのdownloadを1件ずつ送る

未取り込みのdownloadには単品取り込み操作を表示します。商品ページで1商品に複数のdownloadがある場合、各Import Eagleは対応する「その他のDL方法」の直下へ表示されます。

Batch import

表示中の商品を上から順番に取り込む

libraryとgiftsでは、表示中の商品から未取り込みのdownloadを集め、画面右下へ商品名とFile名を一覧表示します。

  1. 一覧で取り込み対象を確認します。
  2. すべて取り込むを選びます。
  3. 取り込み待ちではない対象を上から順番に処理します。

表示中の対象がすべて取り込み済みになると、一覧は非表示になります。

Refresh

Eagleで選択したアイテムを再取得する

EagleでBoothMetaタグ付きのJSONアイテムを1件または複数選択し、右クリックメニューからBooth Compatを実行します。選択アイテムのBOOTH商品情報とカスタムサムネイルを順番に再取得します。商品名に/が含まれていても、Eagleアイテム名では空白へ置き換え、JSONには元の商品名を残します。1件失敗しても残りを続け、最後に更新件数と失敗件数を通知します。取り込み済みdownloadの履歴とEagleで付けたタグは維持します。

BoothMeta以外のアイテムが混ざっている場合は対象外として通知します。選択内にBoothMetaがない場合は、通常のBOOTH商品URL入力画面が開きます。

Download flow

BOOTH標準downloadを使う

単品と一括は同じ取り込み経路を使用します。Eagle bridgeへ商品情報とdownload要求を登録した後、BOOTHの通常downloadを別tabで開始します。

設定先: Eagle libraryとEagleへの取り込み先はUnityのPreferences / 4OF / ee4vで管理します。
