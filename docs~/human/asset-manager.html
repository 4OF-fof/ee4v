Open

最初は3つまとめて開く

ee4v / Window / Asset Manager / Open Allを選ぶと、Navigation、Main、Informationをまとめて開きます。統合Windowではなく、それぞれ独立したWindowです。Unityのlayoutに合わせて横並びやdock配置にできます。

  • ee4v / Window / Asset Manager / Navigation
  • ee4v / Window / Asset Manager / Main
  • ee4v / Window / Asset Manager / Information

個別menuから開いた場合も、3つのWindowは同じ選択状態と表示位置を共有します。

Modification workflow

派生アセットをキャラクリのように編集する

ee4v / Window / Asset Manager / Modification Workflowを開くと、AssetManagerで作成済みの派生アセットがカードで並びます。既存の派生アセットを選ぶほか、同じ画面で取り込み済みPrefabから新しい派生アセットを作成できます。編集するキャラクターを決めた後は画面上部でPrefabの組み合わせを操作します。左側には「体型・パーツ」「マテリアル」「表情・アニメーション」「PhysBone」が並びます。Variant名のタブでは全Prefabの候補を、個別PrefabタブではそのPrefabの候補を「体型・パーツ」と「マテリアル」で編集できます。「体型・パーツ」の中で「パーツ」と「体型」を切り替えます。

  1. 派生アセットを選ぶか作る。 最初の画面でPreviewカードを選ぶか、「新しい派生アセット」から取り込み済みItemとPrefab、名前、説明を指定します。作成時はAssetManagerのItem詳細と同じVariant作成機能が使われます。
  2. AssetManagerから直接開くこともできます。 Item詳細の派生アセットカードをダブルクリックすると、そのキャラクターをModification Workflowで直接開けます。
  3. アセットを組み合わせる。 画面上部にはピル型の派生Prefab Variant名と、ブラウザのタブに似た元Prefab・追加Prefabの名前が並びます。サムネイルは表示しません。各Prefabタブの目のアイコンでプレビューだけを一時的に隠せます。ベースPrefabにも使えます。追加Prefabはタブを右クリックして削除できます。Prefabタブを押すと中央PreviewがそのPrefabだけになり、「体型・パーツ」または「マテリアル」の選択が維持されます。「体型・パーツ」内の「パーツ」ではPrefab内の子オブジェクトを一覧で確認し、チェックボックスで表示を切り替えられます。チェックを外すとプレビューから消え、非アクティブ化とEditorOnlyタグを派生Prefabへ保存します。連続したオン・オフは操作が落ち着いてからまとめて保存します。画面を切り替えるか閉じるときは保留分を保存します。変更した部分だけをプレビューと一覧へ反映し、カメラ位置は変わりません。Preferencesの「パーツ一覧から除外する名前の接頭辞」に一致する階層とその子孫は一覧に表示しません。既定値はArmatureです。全体へ戻るにはVariant名のピルを押します。編集する派生アセットを選び直すには、そのピル内の「変更」を押します。末尾の追加アイコンからPrefabを追加できます。
  4. 体型とパーツを調整する。 左側の「体型・パーツ」を開き、右ペイン上部で「パーツ」と「体型」を切り替えます。「体型」で身長やBlendShape、骨格スケールを調整し、「パーツ」で子オブジェクトの表示を切り替えます。Variant名のタブでは全Prefabの候補を、個別PrefabタブではそのPrefabの候補だけを表示します。「パーツ」と「体型」では部位選択と内側の2タブを、「マテリアル」では部位選択を上部に固定します。パーツ選択時にも部位を選ぶとプレビューがその部位へ移動し、骨・追従先・名称からその部位を判定できるオブジェクトだけが一覧に表示されます。判定できないものは全身の一覧で確認できます。カテゴリや内側のタブを切り替えると編集内容は先頭から表示されます。元アセットや他Prefabと共有するMaterialは編集用Material Variantを作ってから変更できます。
  5. 見た目を選ぶ。 「体型・パーツ」の「体型」と「マテリアル」では、「全身」「頭・首」「肩・腕」「手」「胸」「腰・胴」「脚」「足」の順に並ぶ部位を選べます。最初は「パーツ」の全身一覧が開きます。部位を選ぶと中央Previewのカメラが滑らかに移動・回転・拡大します。胸は左斜め下から少し近く低い視点、腰・胴は右斜め下、肩・腕は左斜め上、手は左斜め上、足は正面寄りの左斜め上から表示します。肩・腕と手はPreview上の「左」「右」で表示側を切り替えられます。初期状態はどちらも左です。全身、頭・首、腰・胴は「正面」「背面」で表示方向を切り替えられます。プレビューを手動操作するとカメラの移動アニメーションは止まります。「全身」を選ぶと全体表示になります。全体選択と個別Prefab選択のどちらも全身Previewは同じ距離係数で表示します。Previewの表示リセットでは、選択中の部位と正面／背面・左右の切り替えを保ったまま、その部位の基準視点に戻ります。全身では身長、全BlendShape、骨格スケール、全Materialを確認でき、部位を選ぶと対応する項目に絞られます。全身のサイズでは、VRChatのView Positionが示す眼高をアップロード時の身長としてm単位で確認し、元素材の基準眼高から±1mの範囲で調整できます。変更時はAvatar root scaleとView Positionを一緒に更新し、身長にはXYZの個別設定を表示しません。bone scaleのsliderは50%から200%で、数値入力では範囲外の値も指定できます。各bone scale行の左端にあるchevronを開くと、表情編集のL／R行と同じindentでX、Y、Zの個別調整が表示されます。Renderer名またはMesh名がBodyのメッシュは除外され、それ以外の全BlendShapeが頭・首、胸、腰・胴、肩・腕、手、脚、足へ分類され、判定できないものは全身に表示されます。BlendShapeは表情編集と同じ横一列のsliderと数値入力で0%から100%まで調整できます。全身選択時は頭、胸、腰、肩、腕、手、脚、足のbone scaleを「高度な骨格スケール」に折りたたみ、部位選択時はその部位のscaleを直接表示します。個別boneにはHumanoid Avatarが必要ですが、身長とBody以外のBlendShapeはHumanoid以外でも使用できます。BlendShapeの見出しと、画面上部や高度な骨格スケール内の説明文は表示しません。値は派生Prefabだけに保存され、中央Previewへ即時反映されます。sliderのドラッグ中は各値をPreviewへ即時反映し、Prefab保存は操作終了時にまとめます。マテリアルでは、アバター内のRendererで実際に使われているMaterialがHierarchy pathとslot番号付きの連続した一覧に表示されます。各行右端の表示アイコンを押すと、そのMaterialの表示／非表示を個別に切り替えられ、先頭の「すべて」から選択部位のMaterialを一括操作できます。部位を判定できないMaterialも全身で確認できます。右側の単一スクロール領域には、選択したMaterial名とMaterial Inspectorが1つの枠で開き、Shader固有の色、Texture、描画設定をまとめて編集できます。変更は「プレビュー」と大きな表示領域だけで構成したGame View風Previewへ即時反映されます。グリッド背景と右上の背景切り替え・表示リセットはPhysBone Previewと共通です。
  6. 体型の詳細を開く。 高度な骨格scaleでは、左端のchevronだけでなく部位名を押してもXYZを開閉できます。XYZは表情編集のL／Rと同じように親の部位名より一段内側へ表示されます。Body以外のBlendShape一覧では表情編集と同じ設定で区切り用BlendShapeを除外し、body_base/のような/より前の部分は表示しません。同じ表示名が複数ある場合は番号と二段目のRenderer名で区別でき、ポインターを重ねるとRendererのHierarchy pathと元のBlendShape名を確認できます。
  7. BlendShapeを整理する。 表情と共通のFBX別プリセットにある「見た目の部位」で胸や腰・胴などを指定すると、体型タブの部位別一覧に反映されます。「表情のみ」は見た目から除外し、「全身のみ」は全身にだけ表示します。部位が「自動」なら従来の名前判定を使います。BodyメッシュのBlendShapeも部位を明示すれば見た目に表示できます。見た目グループ名または役割名が同じBlendShapeは部位内でまとめて表示されます。体型タブにプリセット編集ボタンはありません。スライダーの値は派生Prefabへ保存されます。
  8. 表情とアニメーション付き表情を作る。 「表情・アニメーション」では既存のFace Expression画面をそのまま使用します。Avatar Preview、表情Clip library、BlendShape、複数pose、遷移時間、Loop、再生、timelineを1画面で操作できます。
  9. PhysBone Colliderを設定する。 「PhysBone」では既存のPhysBone Collider Setupを使用します。派生Prefab rootが最初の検出対象になり、候補の配置、Colliderごとの調整、PhysBoneへの割り当てを確認してから「アバターへ適用」で派生Prefabへ保存できます。

Layout

Windowごとの役割

Navigation

最上部のImport済みに続き、全件、未所属、Archive、Tag、Collectionの表示先を切り替えます。

Main

Item一覧、File一覧、検索、並び替え、Item詳細を表示する作業領域です。

Information

最後に選択したItemのサムネイル、名前、説明、Tag、BOOTH情報などを表示します。

状態の共有

Navigationで表示先を変えたりMainでItemを選んだりすると、ほかのWindowにも反映されます。

複数選択時: Informationには末尾3件までのサムネイルを重ねて表示し、編集formは表示しません。最後に操作したItemが最前面になります。

Browse

Itemを探して選ぶ

  1. 表示先を選ぶ。 NavigationからImport済み、全件、未所属、Archive、TagまたはCollectionを選びます。最上部のImport済みでは、現在のProject内に取り込み済みの実Assetが存在するItemだけを表示し、取り込み先フォルダーだけが残るItemは除外します。
  2. 必要なら検索対象を変える。 Mainの検索欄にある検索iconから、名前、説明、Tagを個別に対象へ含めます。未所属Fileでは名前検索がFile名へ適用されます。
  3. 並び順を選ぶ。 Itemは名前、作成日、更新日、File数で並び替えられ、逆順にもできます。
  4. 選択する。 通常clickで単一選択、Ctrlで追加・解除、Shiftで直前の基準Itemから範囲選択します。

Escapeまたはカード外の空白を左clickすると選択を解除します。Itemをdouble clickするとMainがItem詳細へ切り替わります。

Details & import

Fileの中身と取り込み先を確認する

Item詳細は、左の検索付きFile Treeと右の詳細表示に分かれます。File Treeの先頭にItem概要、その下に所属Fileを表示し、ZIPとUnityPackageの解析内容は子階層として展開します。

選択対象右側に表示する内容
概要名前、Tag、Item Target、File数、形式、Source、BOOTH情報、合計size、作成・更新日時
File形式、操作、実体単位のDependency Targetなどの取り込み設定
File内の内容path、種別、size、取り込み済みかどうか

取り込みの流れ

  1. FileまたはFile内の実体へItem Targetを設定します。TargetをGroupにすると、Import時にGroupごとに1件を選べます。
  2. 必要な場合はFile詳細からDependency Targetを設定します。
  3. ItemのImport、またはFile Treeのcontext menuから1実体のImportを実行します。

取り込めない対象: ZIP自身、ZIP内のZIP、Directoryは1実体Importの対象になりません。ItemのImportは単一Itemが選択され、Item Targetが設定済みの場合に有効になります。

Codexで取り込み済みPrefabを確認する

ee4v MCPでは名前、説明、TagでItemを絞った後、Itemに記録された取り込み済みGUIDと派生Prefabから、Project内に実在するPrefab候補を取得できます。候補はサムネイルではなくUnityの隔離Preview環境で撮影し、Renderer、Material slot、Shader、Texture、Mesh、BlendShapeを読み取り専用で調査できます。Material編集は調査結果を既存Unity MCPへ渡して行います。

先にImportが必要: 未ImportのZIPやunitypackageをMCPが自動Importすることはありません。PrefabがProjectに存在しないItemはpreviewできず、候補なしの理由が返ります。

Organize

Tag、Collection、Archiveで整理する

名前・説明・Tag

名前と説明は入力欄からfocusが外れた時点、Tagは選択Popupを閉じた時点で保存されます。保存buttonはありません。Eagle由来Itemの名前と説明は読み取り専用ですが、Tagは編集できます。

Collection

NavigationのCollection見出しから作成します。条件はGroupごとにANDまたはORを選び、条件またはGroupをNOTで反転できます。編集と削除はCollectionの右click menuから行います。

Archive

Itemカードの右click menuからArchive、復元、削除を実行します。Archive済みItemでは復元と削除だけを表示し、削除は選択対象がすべてArchive済みの場合に確認dialogを経て実行します。

Sources

Eagleとee4vを同期する

外部pathはAsset Manager内ではなく、Preferences / 4OF / ee4vで設定します。Mainの再読み込みbuttonはEagleとee4vを順番に同期してから一覧を更新します。片方が失敗しても残りの同期は続行し、errorはUnity Consoleへ表示します。

Editor session開始時の自動同期も設定できます。現在対応するSourceはEagleとee4vです。
