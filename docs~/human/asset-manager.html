Open

最初は3つまとめて開く

ee4v / Window / Asset Manager / Open Allを選ぶと、Navigation、Main、Informationをまとめて開きます。統合Windowではなく、それぞれ独立したWindowです。Unityのlayoutに合わせて横並びやdock配置にできます。

  • ee4v / Window / Asset Manager / Navigation
  • ee4v / Window / Asset Manager / Main
  • ee4v / Window / Asset Manager / Information

個別menuから開いた場合も、3つのWindowは同じ選択状態と表示位置を共有します。

Modification workflow

派生アセットをキャラクリのように編集する

ee4v / Window / Asset Manager / Modification Workflowを開くと、AssetManagerで作成済みの派生アセットがカードで並びます。既存の派生アセットを選ぶほか、同じ画面で取り込み済みPrefabから新しい派生アセットを作成できます。編集するキャラクターを決めた後は画面上部でPrefabの組み合わせを操作します。左側には「体型・パーツ」「マテリアル」「表情・アニメーション」「PhysBone」が並びます。Variant名のタブでは全Prefabの候補を、個別PrefabタブではそのPrefabの候補を「体型・パーツ」と「マテリアル」で編集できます。「体型・パーツ」の中で「パーツ」と「体型」を切り替えます。

  1. 派生アセットを選ぶか作る。 最初の画面でPreviewカードを選ぶか、「新しい派生アセット」から取り込み済みItemとPrefab、名前、説明を指定します。作成時はAssetManagerのItem詳細と同じVariant作成機能が使われます。
  2. AssetManagerから直接開くこともできます。 Item詳細の派生アセットカードをダブルクリックすると、そのキャラクターをModification Workflowで直接開けます。
  3. アセットを組み合わせる。 画面上部にはピル型の派生Prefab Variant名と、ブラウザのタブに似た元Prefab・追加Prefabの名前が並びます。サムネイルは表示しません。各Prefabタブの目のアイコンでプレビューだけを一時的に隠せます。ベースPrefabにも使えます。追加Prefabはタブを右クリックして削除できます。Prefabタブを押すと中央PreviewがそのPrefabだけになり、「体型・パーツ」または「マテリアル」の選択が維持されます。「体型・パーツ」内の「パーツ」ではPrefab内の子オブジェクトを一覧で確認し、チェックボックスで表示を切り替えられます。チェックを外すとプレビューから消え、非アクティブ化とEditorOnlyタグを派生Prefabへ保存します。連続したオン・オフは操作が落ち着いてからまとめて保存します。画面を切り替えるか閉じるときは保留分を保存します。変更した部分だけをプレビューと一覧へ反映し、カメラ位置は変わりません。Preferencesの「パーツ一覧から除外する名前の接頭辞」に一致する階層とその子孫は一覧に表示しません。既定値はArmatureです。全体へ戻るにはVariant名のピルを押します。編集する派生アセットを選び直すには、そのピル内の「変更」を押します。末尾の追加アイコンからPrefabを追加できます。
  4. 体型とパーツを調整する。 左側の「体型・パーツ」を開き、右ペイン上部で「パーツ」と「体型」を切り替えます。「体型」で身長やBlendShape、骨格スケールを調整し、「パーツ」で子オブジェクトの表示を切り替えます。Variant名のタブでは全Prefabの候補を、個別PrefabタブではそのPrefabの候補だけを表示します。「パーツ」と「体型」では部位選択と内側の2タブを、「マテリアル」では部位選択を上部に固定します。パーツ選択時にも、対応するHumanoid boneか衣装のSkinnedMeshRendererが参照するboneがある部位を選ぶとプレビューがそのboneへ移動し、骨・追従先・名称からその部位を判定できるオブジェクトだけが一覧に表示されます。対応するboneがない部位は選択できません。部位を判定できないオブジェクトは全身の一覧で確認できます。カテゴリや内側のタブを切り替えると編集内容は先頭から表示されます。元アセットや他Prefabと共有するMaterialは編集用Material Variantを作ってから変更できます。
  5. 見た目を選ぶ。 「体型・パーツ」の「体型」と「マテリアル」では、「全身」「頭・首」「肩・腕」「手」「胸」「腰・胴」「脚」「足」の順に並ぶ部位を選べます。最初は「パーツ」の全身一覧が開きます。対応するHumanoid boneか衣装のSkinnedMeshRendererが参照するboneがある部位を選ぶと、中央Previewのカメラがそのboneを基準に滑らかに移動・回転・拡大します。boneがない部位はグレーアウトします。全身はboneがないPrefabでも選べます。胸は左斜め下から少し近く低い視点、腰・胴は右斜め下、肩・腕は左斜め上、手は左斜め上、足は正面寄りの左斜め上から表示します。肩・腕と手はPreview上の「左」「右」で表示側を切り替えられます。初期状態はどちらも左です。全身、頭・首、腰・胴は「正面」「背面」で表示方向を切り替えられます。プレビューを手動操作するとカメラの移動アニメーションは止まります。「全身」を選ぶと全体表示になります。全体選択と個別Prefab選択のどちらも全身Previewは同じ距離係数で表示します。Previewの表示リセットでは、選択中の部位と正面／背面・左右の切り替えを保ったまま、その部位の基準視点に戻ります。全身では身長、全BlendShape、骨格スケール、全Materialを確認でき、部位を選ぶと対応する項目に絞られます。全身のサイズでは、VRChatのView Positionが示す眼高をアップロード時の身長としてm単位で確認し、元素材の基準眼高から±1mの範囲で調整できます。変更時はAvatar root scaleとView Positionを一緒に更新し、身長にはXYZの個別設定を表示しません。bone scaleのsliderは50%から200%で、数値入力では範囲外の値も指定できます。各bone scale行の左端にあるchevronを開くと、表情編集のL／R行と同じindentでX、Y、Zの個別調整が表示されます。Renderer名またはMesh名がBodyのメッシュは除外され、それ以外の全BlendShapeが頭・首、胸、腰・胴、肩・腕、手、脚、足へ分類され、判定できないものは全身に表示されます。BlendShapeは表情編集と同じ横一列のsliderと数値入力で0%から100%まで調整できます。全身選択時は頭、胸、腰、肩、腕、手、脚、足のbone scaleを「高度な骨格スケール」に折りたたみ、部位選択時はその部位のscaleを直接表示します。個別boneにはHumanoid Avatarが必要ですが、身長とBody以外のBlendShapeはHumanoid以外でも使用できます。BlendShapeの見出しと、画面上部や高度な骨格スケール内の説明文は表示しません。値は派生Prefabだけに保存され、中央Previewへ即時反映されます。sliderのドラッグ中は各値をPreviewへ即時反映し、Prefab保存は操作終了時にまとめます。マテリアルでは、アバター内のRendererで実際に使われているMaterialがHierarchy pathとslot番号付きの連続した一覧に表示されます。各行右端の表示アイコンを押すと、そのMaterialの表示／非表示を個別に切り替えられ、先頭の「すべて」から選択部位のMaterialを一括操作できます。部位を判定できないMaterialも全身で確認できます。右側の単一スクロール領域には、選択したMaterial名とMaterial Inspectorが1つの枠で開き、Shader固有の色、Texture、描画設定をまとめて編集できます。変更は「プレビュー」と大きな表示領域だけで構成したGame View風Previewへ即時反映されます。グリッド背景と右上の背景切り替え・表示リセットはPhysBone Previewと共通です。
  6. 体型の詳細を開く。 高度な骨格scaleでは、左端のchevronだけでなく部位名を押してもXYZを開閉できます。XYZは表情編集のL／Rと同じように親の部位名より一段内側へ表示されます。Body以外のBlendShape一覧では表情編集と同じ設定で区切り用BlendShapeを除外し、body_base/のような/より前の部分は表示しません。同名のBlendShapeは一つの行にまとまり、左端の矢印を開くとRendererごとの値を調整できます。既にMA Blendshape Syncでつながる参照元と追従先も一緒に表示します。まとめた行の操作は全体を同じ値で同期し、個別行の操作はMAの補正値として保存されます。個別行にはRenderer名が表示され、ポインターを重ねるとHierarchy pathと元のBlendShape名を確認できます。
  7. BlendShapeを整理する。 表情と共通のFBX別プリセットにある「見た目の部位」で胸や腰・胴などを指定すると、体型タブの部位別一覧に反映されます。「表情のみ」は見た目から除外し、「全身のみ」は全身にだけ表示します。部位が「自動」なら従来の名前判定を使います。BodyメッシュのBlendShapeも部位を明示すれば見た目に表示できます。見た目グループ名または役割名が同じBlendShapeは部位内でまとめて表示されます。体型タブを開いたとき、表示対象のFBXにプリセットがなければ自動生成します。保存済みのプリセットは上書きしません。プリセットはFace Expression画面またはee4v MCPから整えられます。体型タブにプリセット編集ボタンはありません。スライダーの値は派生Prefabへ保存されます。
  8. 表情とアニメーション付き表情を作る。 「表情・アニメーション」では既存のFace Expression画面をそのまま使用します。Avatar Preview、表情Clip library、BlendShape、複数pose、遷移時間、Loop、再生、timelineを1画面で操作できます。
  9. PhysBone Colliderを設定する。 「PhysBone」では既存のPhysBone Collider Setupを使用します。派生Prefab rootが最初の検出対象になり、候補の配置、Colliderごとの調整、PhysBoneへの割り当てを確認してから「アバターへ適用」で派生Prefabへ保存できます。

Layout

Windowごとの役割

Navigation

最上部のImport済みに続き、全件、未所属、Archive、Tag、Collectionの表示先を切り替えます。メニューとCollectionを同じ高さの行に揃え、現在の表示先を青い背景と左端の細いアクセントで示します。

Main

Item一覧、File一覧、検索、並び替え、Item詳細を表示する作業領域です。

Information

最後に選択したItemのサムネイル、名前、説明、Tag、BOOTH情報などを表示します。

状態の共有

Navigationで表示先を変えたりMainでItemを選んだりすると、ほかのWindowにも反映されます。

複数選択時: Informationには末尾3件までのサムネイルを重ねて表示し、編集formは表示しません。最後に操作したItemが最前面になります。

Browse

Itemを探して選ぶ

  1. 表示先を選ぶ。 NavigationからImport済み、全件、未所属、Archive、Tag、Collectionを選びます。EagleのフォルダはNavigationに表示しません。最上部のImport済みでは、現在のProject内に取り込み済みの実Assetが存在するItemだけを表示し、取り込み先フォルダーだけが残るItemは除外します。
  2. 必要なら検索対象を変える。 Mainの検索欄にある検索iconから、名前、説明、Tagを個別に対象へ含めます。未所属Fileでは名前検索がFile名へ適用されます。
  3. 並び順を選ぶ。 Itemは名前、作成日、更新日、File数で並び替えられ、逆順にもできます。
  4. 選択する。 通常clickで単一選択、Ctrlで追加・解除、Shiftで直前の基準Itemから範囲選択します。

Escapeまたはカード外の空白を左clickすると選択を解除します。Itemをdouble clickするとMainがItem詳細へ切り替わります。

Details & import

Fileの中身と取り込み先を確認する

Item詳細は、左の検索付きFile Treeと右の詳細表示に分かれます。File Treeの先頭にItem概要、その下に所属Fileを表示します。ZIPとUnityPackageは展開すると内容を読み込み、読み込み中は「解析中…」と表示します。File Treeで検索した場合は未解析のFileも読み込み、内容を検索します。

File TreeのPNG・JPEG・PSDへマウスを重ねると、画像とFile名をプレビューできます。ZIPとUnityPackageの中にある画像にも対応します。行からマウスを離すとプレビューは閉じます。

File TreeではCtrl+クリックで選択を追加・解除し、Shift+クリックで起点からまとめて選択できます。複数選択時も右側には単体Fileと同じヘッダーと設定を表示し、File IDだけを省きます。所属Itemの移動、Archive・復元・削除は選択したFileへまとめて適用されます。依存Targetの編集は取り込み可能な選択実体へまとめて適用されます。選択済みの行を右クリックすると、ImportとTarget操作を選択全体へ適用できます。ImportとTarget設定は取り込み可能なFile・実体だけが対象です。依存Targetは選択した実体ごとに設定され、保存すると選択した全実体の依存先が同じ内容に置き換わります。ZIP自身には設定できないため、中のFileを選択します。

Target選択のポップアップでは、候補の行またはチェックボックスをクリックして選びます。ZIP自身は選べないため、ZIPを展開して中のFileを選んでから保存してください。

依存先の候補には依存元自身を表示しません。同じZIPに別の実体がある場合、その実体は候補に残ります。

以前の依存設定: File単位の依存関係は実体単位へ自動変換されません。ZIP内の依存元実体を選んで設定し直してください。

ポップアップは開くたびに候補を折りたたんで表示します。未解析のZIPやUnityPackageは展開したFileだけを解析し、完了後に内容を表示します。内容を検索した場合は未解析の候補も読み込みます。

選択対象右側に表示する内容
概要名前、Tag、Item Target、File数、形式、Source、BOOTH情報、合計size、作成・更新日時
File形式、操作、所属Item。ZIP以外のFile自身には依存Targetも設定可能
複数選択単体Fileと同じヘッダーと設定一覧。File IDは表示しない
File内の内容path、種別、size、取り込み済みかどうか。取り込み可能な実体には依存Targetも設定可能

取り込みの流れ

  1. FileまたはFile内の実体へItem Targetを設定します。TargetをGroupにすると、Import時にGroupごとに1件を選べます。
  2. 必要な場合は、依存元になるFile自身またはZIP内の実体をFile Treeで選び、その詳細からDependency Targetを設定します。
  3. ItemのImport、File Treeのcontext menuから1実体のImport、またはFile Treeで複数選択してImportを実行します。

取り込めない対象: ZIP自身、ZIP内のZIP、Directoryは1実体Importの対象になりません。ItemのImportは単一Itemが選択され、Item Targetが設定済みの場合に有効になります。

Codexで取り込み済みPrefabを確認する

ee4v MCPでは名前、説明、TagでItemを絞った後、Itemに記録された取り込み済みGUIDと派生Prefabから、Project内に実在するPrefab候補を取得できます。候補はサムネイルではなくUnityの隔離Preview環境で撮影し、Renderer、Material slot、Shader、Texture、Mesh、BlendShapeを読み取り専用で調査できます。Material編集は調査結果を既存Unity MCPへ渡して行います。

先にImportが必要: 未ImportのZIPやunitypackageをMCPが自動Importすることはありません。PrefabがProjectに存在しないItemはpreviewできず、候補なしの理由が返ります。

Organize

Tag、Collection、Archiveで整理する

名前・説明・Tag

名前と説明は入力欄からfocusが外れた時点、Tagは選択Popupを閉じた時点で保存されます。保存buttonはありません。Eagle由来Itemの名前と説明、Eagle由来TagはEagle側で編集します。ee4vで追加したTagは編集できます。Eagleのカスタムサムネイルも同期し、再読み込み後に表示へ反映します。

Collection

NavigationのCollection見出し右側にある、追加アイコン付きの「新規」から作成します。条件はGroupごとにANDまたはORを選び、条件またはGroupをNOTで反転できます。編集と削除はCollectionの右click menuから行います。

Collection一覧は枠線を省いたすっきりした行で、名前だけを表示します。見出しと各行に件数は表示しません。選択中の行は上部メニューと共通の青い背景と左端のアクセントで示します。行自体をドラッグして順序を変更できます。移動先の行の上半分へ落とすとその前、下半分へ落とすとその後へ移動します。右click menuの「上へ移動」「下へ移動」でも操作できます。順序は保存され、新規Collectionは末尾へ追加されます。

Tag一覧

NavigationのTagを選ぶと、Tag名とItem数をまとめた軽いPillが横に並び、画面幅に合わせて折り返します。階層部分と件数は小さな補助文字で表示します。検索欄でTagの完全pathを部分一致検索でき、その下にある「使用数順」「名前順」の文字タブで並び順を切り替えられます。選択中の並び順は下線で示します。件数は下位Tagを含む未ArchiveのItem数で、同じItemは重複して数えません。

Tag一覧は名前順で開きます。A、B、Cなどの頭文字の見出しを付け、その下にPillをまとめます。数字は「0–9」、記号は「#」、ひらがな・カタカナなどはその頭文字で区切ります。漢字で始まるTagは一覧の末尾にある「その他」へまとめます。検索中は一致したTagがある見出しだけを表示します。

Pillを選ぶと、そのTagまたは下位Tagを持つItemへ絞り込みます。長いTag名はPill内で省略され、マウスを重ねると完全pathと件数を確認できます。検索に一致しない場合は検索語を消去して一覧へ戻せます。Item一覧からTag一覧へ戻ると、検索語と並び順を維持します。

Archive

Itemカードの右click menuからArchive、復元、削除を実行します。Archive済みItemでは復元と削除だけを表示し、削除は選択対象がすべてArchive済みの場合に確認dialogを経て実行します。

Sources

Eagleとee4vを同期する

外部pathはAsset Manager内ではなく、Preferences / 4OF / ee4vで設定します。Mainの再読み込みbuttonはEagleとee4vを順番に同期してから一覧を更新します。片方が失敗しても残りの同期は続行し、errorはUnity Consoleへ表示します。

Editor session開始時の自動同期も設定できます。現在対応するSourceはEagleとee4vです。
