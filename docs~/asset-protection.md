# Asset Protection

Asset ProtectionはAssetManagerの内部モジュールです。AssetManagerからUnity Projectへ取り込んだAssetの直接編集を防ぎます。保護対象はAssetManagerのSQLiteに登録された取り込み済みAsset GUIDです。別の保護設定は持ちません。

Editor起動時に`GetImportedAssetAssociations`からGUIDを読み、取り込みGUIDの変更時に一覧を更新します。登録GUIDに一致するAssetはUnityの編集可否判定で編集不可にします。Inspectorへ直接表示した保護対象BlendTreeには`HideFlags.NotEditable`を適用し、編集領域へ解除できない半透明の警告を重ねて操作を遮断します。この追加保護はBlendTreeだけを対象とし、判定にはInspector全体の選択ではなく、各Editorが実際に描画するtargetを使用します。Animation Windowで開いている保護対象Clipには`HideFlags.NotEditable`を適用し、保護対象Animator Controllerを表示しているAnimator Windowは内容を無効化します。これによりBlendTree、キーフレーム、ステートグラフからの編集を防ぎます。pathではなくGUIDを照合するため、Project内で移動しても保護は継続します。

保護対象PrefabをPrefab Modeで開くと、すべてのHierarchy WindowのGameObject一覧領域へ半透明の警告を重ねて操作を遮断します。Prefab Modeの終了操作は覆いません。Prefab Mode内のObjectを表示するInspectorでも編集領域へ同じ警告を表示します。「編集を続ける」を押すと現在のPrefab Modeに限って両方の警告を外します。Prefab Modeを閉じるか別のPrefabへ移動した場合は、次に保護対象Prefabを開いたときに再び警告します。

保護AssetはUnityの保存対象からも除外します。ただしNDMF Consoleの自動修正など、NDMFのアセンブリから呼び出された修正操作は保護対象にも適用します。削除は制限しません。

編集するときはUnity標準機能を使用し、PrefabやMaterialはVariantを作成します。VariantがないAssetは複製してから編集します。Asset Protection自身は編集用Assetを作成しません。
