# Asset Protection

Asset ProtectionはAssetManagerからUnity Projectへ取り込んだAssetの直接編集を防ぎます。保護対象はAssetManagerのSQLiteに登録された取り込み済みAsset GUIDです。別の保護設定は持ちません。

Editor起動時に`GetImportedAssetAssociations`からGUIDを読み、取り込みGUIDの変更時に一覧を更新します。登録GUIDに一致するAssetはUnityの編集可否判定で編集不可にします。Animation Windowで開いている保護対象Clipには`HideFlags.NotEditable`を適用し、保護対象Animator Controllerを表示しているAnimator Windowは内容を無効化します。これによりキーフレームとステートグラフの編集を防ぎます。pathではなくGUIDを照合するため、Project内で移動しても保護は継続します。

保護AssetはUnityの保存対象からも除外します。削除は制限しません。

編集するときはUnity標準機能を使用し、PrefabやMaterialはVariantを作成します。VariantがないAssetは複製してから編集します。Asset Protection自身は編集用Assetを作成しません。
