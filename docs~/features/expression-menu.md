# Expression Menu

`src/Editor/Feature/Avatar/ExpressionMenu`の`Ee4v.ExpressionMenu.Editor`は、Unity 2022.3 / VRChatのExpression MenuをEdit Modeで編集します。AssetManagerの「Expression Menu」カテゴリと単独の`ee4v/Window/Avatar/Expression Menu`が同じ`ExpressionMenuView`を使用します。Play ModeのControlsは既存GestureManagerによる動作確認を使用します。

## 新規項目のテンプレート

円形メニューの「＋／追加」で通常のメニュー項目と3種類のMAテンプレートを選択します。MAの選択肢は「機能（Component名）」形式で、オブジェクト表示／非表示（MA Object Toggle）、マテリアル差し替え（MA Material Swap）、BlendShape変更（MA Shape Changer）を登録します。Object ToggleはON用・OFF用に分けず一つのテンプレートとして扱います。選択した項目は現在表示しているrootまたはサブメニューへ追加し、作成後に合成表示へ切り替えます。出所componentの参照で新規項目とその階層・ページを特定し、項目設定を表示します。

通常項目もMAテンプレートも、MA Menu Itemを持つ専用Prefabを作成します。MAテンプレートでは同じGameObjectへ選択したMA componentを追加します。Object ToggleとMaterial Swapは空の設定行を一つ持ち、Shape Changerは一覧から対象を選択するまで設定行を持ちません。Menu ItemはToggleで、固有パラメーター名、値1、同期・値保存を初期設定します。サブメニューをChildrenで構成できるように`MenuSource`をChildrenへ設定します。新規項目の登録はMA componentで構成します。

項目を選択すると、MA Menu Itemの最寄りの子componentに対応する簡易フォームを表示します。3種類のテンプレートと同じcomponentを持つ既存項目にも使用し、別の子Menu Itemに属するcomponentは表示しません。共通項目は名前・アイコン・他プレイヤーへの同期です。Object Toggleは切り替え対象Objectと対象ごとの初期ON/OFF、Material Swapは差し替え前後のMaterial、Shape Changerは対象SkinnedMesh・BlendShape・初期値（0〜100）を編集します。Object ToggleとMaterial Swapは対象行の追加・削除、Shape Changerは一覧のチェックによる選択・解除に対応し、どのテンプレートも項目全体を削除できます。種類・parameter・値保存・自動値・条件反転・component削除などの詳細設定はテンプレートの画面に配置しません。無効時への復帰とアニメーション生成はMAが行います。

入力の確定と選択・チェックの変更で設定を即時適用し、専用Prefabへ保存します。文字と数値の入力はEnterまたはフォーカスを外した時に確定します。変更はUndoへ記録し、Prefab overrideと作業Scene変更をホストへ通知します。Object Toggleの初期ON/OFFは各対象のActiveへ保存し、MA Menu ItemのisDefaultを有効にして初期状態へ反映します。条件が反転している既存componentではActiveと画面の初期値を反転して対応させます。対象の選択・追加・初期値変更でもisDefaultを有効にします。Shape ChangerもisDefaultを有効にして初期値を適用し、選択と初期値編集時もisDefaultを有効にします。Material Swapの新規項目はアバター全体を対象にします。既存componentの画面に公開しない設定値は維持します。専用Prefab以外の既存Scene componentは通常のPrefab保存・Variant保存で保存します。読み取り専用、immutable PrefabとPlay Modeでは編集を無効にします。生成した項目の削除はそのGameObjectと付属MA componentをUndoでまとめて除去し、保存済みPrefab assetを残します。既存のMA Menu Itemの削除はそのcomponentだけを除去します。

対象は編集中アバターの内部だけに限定し、アバターrootの無効化を拒否します。新しく指定する対象はroot相対pathを持つMAのAvatarObjectReferenceへ変換し、同名の兄弟Objectと名前に`/`を含むObjectを拒否します。これは専用Prefabの保存時に外部Scene参照へ依存しないためです。対象の削除・改名と存在しないBlendShapeは設定欄へエラー表示します。

## BlendShapeの選択

体型・パーツタブと同じ共有の名前プリセット・部位分類・お気に入りを使用し、部位と役割を折りたためる一覧からチェックで対象を選択します。BlendShape名・Renderer path・役割で検索でき、表情を含むアバター内の候補を表示します。見出し用BlendShapeは一覧から除きます。選択欄にはスライダーを配置せず、選択した行だけに初期値（0〜100）の数値入力を表示します。選択解除で対応するMA設定行を削除します。お気に入りと分類位置の同じ対象はチェック・数値を即時に同期します。検索とグループの開閉はcomponentを変更しません。消失した対象・BlendShapeの保存済み行はエラーと削除操作を表示します。分類とお気に入りはShared/AvatarEditingの公開APIを使用し、AvatarPartsやFaceExpressionのassemblyへ依存しません。

## 表示と出所

統合画面と単独Windowのどちらもアバターの3Dプレビューを表示せず、円形メニューと項目設定に編集領域を使用します。統合画面のメニューは合成表示に固定し、表示・編集元の選択欄とメニュー名を表示しません。単独Windowだけに表示・編集元の選択欄とメニュー名を表示します。上部に説明用HintBox、再読み込み・メニューasset保存の操作は配置しません。編集エラーと読み取り専用の案内は必要時に表示します。項目や表示元の選択と変更操作の後にメニューを解決し直します。

初期表示はDescriptorのExpression MenuへModular AvatarのMenu Installer、Menu Item、Menu Group、Menu Install Targetを解決した構成です。円形メニューはGestureManagerの`GmgCircleElement`、`RadialMenuUtility`、`RadialCursor`を使用し、GMと同じ300pxの円、100pxの中央円、50pxのアイコン、扇形のグラデーション・区切り線・設定色・カーソルを描画します。戻るを上端に置き、時計回りに表示項目、末尾操作の順で均等に分割します。Nextがあるページの末尾操作はNextだけで、最後のページだけに「＋／追加」を配置します。「＋」をクリックするとテンプレートの選択肢を表示します。テンプレートを選ぶと現在のメニューへ項目を追加し、新規項目の設定欄を表示します。8項目を超える場合は同じメニュー内の末尾ページを表示します。Prefabを編集できない状態やPlay Modeでは追加を無効にします。ホバー・キーボードフォーカス・選択中の項目はGMの選択色と1.1倍の拡大で強調します。既定アイコン・戻る・型の補助アイコンはGMのリソースを使用し、独自の追加とNextにはFluent UI System Iconsを使用します。文字は`UiTextFactory`経由の要素でGMと同じ12pxへ揃えます。選択は扇形の範囲で判定し、項目選択で設定を開き、サブメニューと戻る操作で階層を辿ります。8項目を超える合成メニューは7項目とNextへ分割して表示します。追加・戻る・Nextはメニューassetの8項目上限に含めません。ページ移動は表示だけの操作で、元assetを分割しません。パラメーターを動かしてアバターを再生する操作はPlay ModeのControlsで行います。

円形メニューのアイコンと文字は扇形の当たり判定と独立した、入力を受け取らない表示レイヤーへ配置します。ラベルは`UiTextFactory`のUI Toolkit描画を使用し、100pxの固定幅で折り返して高さの切り捨てを行いません。ホバーは円形メニュー内のポインター座標から固定した扇形で判定します。拡大は表示レイヤーだけへ適用し、強調状態の変化時だけアニメーションを開始します。反転時は前のアニメーションを停止し、Viewの破棄時に解放します。

円形メニューのサブメニュー項目はクリックで直接開き、開いているサブメニュー項目自体の設定を表示します。子項目を選択すると、その子項目の設定へ切り替わります。ページ移動や親サブメニューへの戻る操作で選択が解除された場合も、現在のサブメニュー項目の設定へ戻ります。サブメニューへ移動せず項目自体を編集するときは右クリックの「項目の設定」を使用します。開いているサブメニュー項目を削除、またはSubMenu以外へ変更した場合は親メニューへ戻ります。その他の項目はクリックで設定欄を表示します。階層移動は編集元への書き込み可否や出所の一意性に依存しません。

単独Windowの「表示・編集元」からDescriptorとMA Installerの参照するメニューasset、MA Menu Itemを直接選択できます。合成表示の項目は名前・型・アイコン・値・パラメーター・Puppet軸・ラベル・サブメニューから元を照合します。候補が複数ある場合は合成表示からの変更を禁止し、単独Windowの編集元の選択で確定します。外部の編集で元のControlが差し替わった場合も変更を拒否して項目の再選択を促します。

通常項目の設定欄は編集元のObjectを表示し、テンプレート項目は簡易フォームを表示します。読み取り専用、または出所を一意に判別できない項目も設定値を表示し、入力と変更操作を無効にします。共有assetへの編集は、それを使用するすべてのアバターへ影響します。通常項目は名前、アイコン、ControlType、parameter、value、subMenu、PuppetのsubParametersと方向ラベル・アイコンを設定できます。通常のMA Menu Itemでは同期・値保存・既定項目・自動値割り当ても設定できます。MA Childrenサブメニューでは子構造を保持し、subMenu assetへの置換は行いません。

## MA専用Prefab

ジェスチャーと同じCoreの共通アセットルートを使用し、`Animation/ExpressionMenu/<アバターPrefab名>/<ID>/MenuItem.prefab`へ項目ごとの専用Prefabを作成して接続します。通常項目とMAテンプレートで保存・配置方法を共用します。rootとassetサブメニューではアバター直下へ配置し、同じGameObjectのMA Menu Installerで登録します。assetサブメニューでは`installTargetMenu`を指定します。MA Childrenサブメニューではその子rootへ配置し、Childrenの取り込みを使用します。親も生成した項目Prefabなら、子の追加・削除に合わせて親Prefabの子構造を保存します。

対象は書き込み可能な通常SceneのAvatar Prefabインスタンスです。生成Prefabは上部item一覧から必ず除外します。AssetManager設定の`assetManager.excludedItemNamePrefixes`は大文字小文字を区別しない名前接頭辞リストで、アバター直下のPrefabを追加除外します。空の既定値では追加除外しません。除外は表示対象の指定で、GameObjectの削除・非アクティブ化は行いません。

## 保存と依存

設定の適用・削除はUndoへ記録します。新規項目の作成と各設定の変更で専用Prefabを保存します。既存メニューassetの適用・削除はそのassetを保存します。専用Prefabの配置と既存Scene componentは既存ホストのAvatar Prefab保存を使用します。Scene、Git、DBは機能側で保存しません。AssetManagerのVariant保存と単独WindowのPrefab保存は従来のホストが所有します。

Coreの公開Localization・ProjectAssetSettings、UI、共有AvatarEditingの編集許可・変更通知・単独Windowに依存します。共通アセットルートのAPIで使用する設定サービス型のためCore.Contracts、共有部位分類のBodyPartCategoryを使用するためCore.Editorも参照します。AvatarEditingを使用する理由は統合版と単独版の対象・保存契約を揃えるためです。他のAvatar機能への参照はありません。VRChat SDK、Modular Avatar runtime、GestureManager runtime / Editorの実際に使うassemblyのみ参照します。GestureManagerへの依存は円形メニューの描画の共用に使用し、Edit Modeの表示・選択でGMのアバター実行モジュールを生成しません。

MAは`src/package.json`の対応範囲（1.18.2以上2.0.0未満）を前提に、内部Editor resolver `VirtualMenu.ForAvatar`、`RootMenuNode`、Childrenのnode keyへアクセスします。バージョン依存箇所はExpressionMenuModelへ隔離します。resolverが取得できない、解決できない場合はエラーを表示し、不完全な合成メニューへの編集へ代替しません。対応範囲でもMA内部API変更時には確認が必要です。

## 手動確認

「＋」から通常項目と3種類のMAテンプレートを選べること、Object Toggleが一つの選択肢であること、root・assetサブメニュー・MA Childrenサブメニューへ追加後に新規項目の設定が表示されること、3種類の簡易フォームに指定した編集項目だけが表示されること、対象行の追加・削除、名前・アイコン・同期・対象ごとの初期ON/OFF・BlendShape初期値の即時保存、BlendShapeの0〜100の入力検証、生成項目の削除とUndo、既存Menu Item削除時のObject保持、アバター外・root無効化・同名pathの拒否、対象消失の表示、生成Prefabのitem一覧除外を確認します。MAによるビルド後にObjectの初期表示とBlendShapeの初期値が反映され、メニューでObject・Material・BlendShapeの状態が切り替わり、無効時に復帰することを確認します。

統合画面と単独Windowで3Dプレビュー、説明用HintBox、再読み込み・メニューasset保存ボタンが表示されず、円形メニューと設定欄が使用可能な横幅へ広がることを確認します。追加メニューのMA項目が「機能（Component名）」形式であること、通常項目とMA項目の専用Prefab生成、各設定変更による再保存、生成項目をSubMenuへ変えて子を追加・削除した際の親Prefabの子構造保存を確認します。統合画面では表示・編集元の選択欄とメニュー名を表示せず、単独Windowでは編集元を切り替えられること、統合画面で別カテゴリへ移動するとプレビューが再表示されることを確認します。

円周の下端・左右端に短い名前と複数行の名前を置き、通常・選択・拡大中に文字が切れないこと、ポインターを項目と中央円の間で往復させても強調と拡大がちらつかないことを確認します。

隔離Unity 2022.3でDescriptorメニュー、root/指定サブメニューへのMA Installer、MA Childrenサブメニューを含むアバターを使用します。合成表示、階層移動、サブメニューを開いた直後と親への戻る操作後の設定表示、開いているサブメニューの削除・型変更後の親への戻り、最後のページだけに配置した「＋」によるroot/サブメニューへの追加、Nextがあるページに「＋」がないこと、追加後の表示元・階層と新規項目の選択、空メニューとページ分割時の「＋」の末尾配置、8項目から9項目へ増えた場合の末尾ページ表示、編集不可時の追加無効、編集可能な項目の即時適用・削除とUndo、読み取り専用または曖昧な項目の入力・削除無効、追加専用Prefabの配置、item一覧の必須除外と設定除外、単独Windowの対象切り替えを確認します。新規自動テストは追加しません。
