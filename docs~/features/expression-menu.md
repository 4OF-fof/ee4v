# Expression Menu

`src/Editor/Feature/Avatar/ExpressionMenu`の`Ee4v.ExpressionMenu.Editor`は、Unity 2022.3 / VRChatのExpression MenuをEdit Modeで編集します。AssetManagerの「Expression Menu」カテゴリと単独の`ee4v/Window/Avatar/Expression Menu`が同じ`ExpressionMenuView`を使用します。Play ModeのControlsは既存GestureManagerによる動作確認を使用します。

## 新規項目のテンプレート

円形メニューの「＋／追加」で通常のメニュー項目、MA Object Toggle、MA Material Swap、MA Material Setter、MA Shape Changerからテンプレートを選択します。選択した項目は現在表示しているrootまたはサブメニューへ追加し、作成後にその項目を選択して設定欄を表示します。MAテンプレートの作成後は合成表示へ切り替え、出所componentの参照で新規項目とその階層・ページを特定します。通常項目は現在の表示・編集元を維持します。

MAテンプレートは選択したMA componentとMA Menu Itemを持つ専用Prefabを作成します。Menu ItemはToggleで、固有パラメーター名、値1、同期・値保存を初期設定します。対象Prefabと同じディレクトリの`<Prefab名>.ExpressionMenu/Gimmicks/<ID>/Gimmick.prefab`へ保存します。rootとassetサブメニューではアバター直下へ配置し、同じGameObjectのMA Menu Installerで登録します。assetサブメニューでは`installTargetMenu`を指定します。MA Childrenサブメニューではその子rootへ配置し、Childrenの取り込みを使用します。生成Prefabは上部item一覧から必ず除外します。MA componentには空の設定行を一つ用意します。

項目を選択すると、MA Menu Itemの最寄りの子componentに対応する設定フォームを項目設定へ表示します。Object Toggleは対象Objectと有効時のactive状態、Material Swapは対象範囲と変更元・変更先Material、Material Setterは対象Renderer・スロット番号・変更先Material、Shape Changerは対象SkinnedMesh・BlendShape・値または頂点削除を設定します。既存のMA Menu Itemに付属する4種類のcomponentも同じフォームで編集できます。別の子Menu Itemに属するcomponentは親項目の設定へ表示しません。設定行とcomponentの削除、条件の反転にも対応します。無効時への復帰とアニメーション生成はMAが行います。

「この編集元を確認し、変更する」を有効にするとMAフォームを編集できます。MA componentの変更は即時にUndoへ記録し、Prefab overrideと作業Scene変更をホストへ通知します。表示名・パラメーターなどのメニュー設定は「設定を適用」で確定します。通常のPrefab保存・Variant保存でScene内のMA設定を保存します。読み取り専用、immutable PrefabとPlay ModeではMA編集を無効にします。生成したテンプレート項目の削除はそのGameObjectと付属MA componentをUndoでまとめて除去し、保存済みPrefab assetを残します。既存のMA Menu Itemの削除はそのcomponentだけを除去します。

対象は編集中アバターの内部だけに限定し、アバターrootの無効化を拒否します。新しく指定する対象はroot相対pathを持つMAのAvatarObjectReferenceへ変換し、同名の兄弟Objectと名前に`/`を含むObjectを拒否します。これは専用Prefabの保存時に外部Scene参照へ依存しないためです。対象の削除・改名と存在しないBlendShapeは設定欄へエラー表示します。Materialスロットは0始まりで、範囲外を拒否します。

## 表示と出所

統合画面と単独Windowのどちらもアバターの3Dプレビューを表示せず、円形メニューと項目設定に編集領域を使用します。統合画面のメニューは合成表示に固定し、表示・編集元の選択欄とメニュー名を表示しません。単独Windowだけに表示・編集元の選択欄とメニュー名を表示します。上部の説明用HintBoxは表示せず、編集エラーと読み取り専用の案内は必要時に表示します。

初期表示はDescriptorのExpression MenuへModular AvatarのMenu Installer、Menu Item、Menu Group、Menu Install Targetを解決した構成です。円形メニューはGestureManagerの`GmgCircleElement`、`RadialMenuUtility`、`RadialCursor`を使用し、GMと同じ300pxの円、100pxの中央円、50pxのアイコン、扇形のグラデーション・区切り線・設定色・カーソルを描画します。戻るを上端に置き、時計回りに表示項目、Next、最後尾の「＋／追加」の順で均等に分割します。「＋」をクリックするとテンプレートの選択肢を表示します。テンプレートを選ぶと現在のメニューへ項目を追加し、新規項目の設定欄を表示します。8項目を超える場合は同じメニュー内の末尾ページを表示します。Prefabを編集できない状態やPlay Modeでは追加を無効にします。ホバー・キーボードフォーカス・選択中の項目はGMの選択色と1.1倍の拡大で強調します。既定アイコン・戻る・型の補助アイコンはGMのリソースを使用し、独自の追加とNextにはFluent UI System Iconsを使用します。文字は`UiTextFactory`経由の要素でGMと同じ12pxへ揃えます。選択は扇形の範囲で判定し、項目選択で設定を開き、サブメニューと戻る操作で階層を辿ります。8項目を超える合成メニューは7項目とNextへ分割して表示します。追加・戻る・Nextはメニューassetの8項目上限に含めません。ページ移動は表示だけの操作で、元assetを分割しません。パラメーターを動かしてアバターを再生する操作はPlay ModeのControlsで行います。

円形メニューのアイコンと文字は扇形の当たり判定と独立した、入力を受け取らない表示レイヤーへ配置します。ラベルは`UiTextFactory`のUI Toolkit描画を使用し、100pxの固定幅で折り返して高さの切り捨てを行いません。ホバーは円形メニュー内のポインター座標から固定した扇形で判定します。拡大は表示レイヤーだけへ適用し、強調状態の変化時だけアニメーションを開始します。反転時は前のアニメーションを停止し、Viewの破棄時に解放します。

円形メニューのサブメニュー項目はクリックで直接開き、開いているサブメニュー項目自体の設定を表示します。子項目を選択すると、その子項目の設定へ切り替わります。ページ移動や親サブメニューへの戻る操作で選択が解除された場合も、現在のサブメニュー項目の設定へ戻ります。サブメニューへ移動せず項目自体を編集するときは右クリックの「項目の設定」を使用します。開いているサブメニュー項目を削除、またはSubMenu以外へ変更した場合は親メニューへ戻ります。その他の項目はクリックで設定欄を表示します。階層移動は編集元への書き込み可否や出所の一意性に依存しません。

単独Windowの「表示・編集元」からDescriptorとMA Installerの参照するメニューasset、MA Menu Itemを直接選択できます。合成表示の項目は名前・型・アイコン・値・パラメーター・Puppet軸・ラベル・サブメニューから元を照合します。候補が複数ある場合は合成表示からの変更を禁止し、単独Windowの編集元の選択で確定します。外部の編集で元のControlが差し替わった場合も変更を拒否して再読み込みを促します。

設定欄は編集元のObjectとasset pathまたはHierarchy pathを表示します。読み取り専用、または出所を一意に判別できない項目も設定値を表示し、入力と変更操作を無効にします。「この編集元を確認し、変更する」を有効にしてから適用・削除・サブメニューassetの生成を行います。共有assetへの編集は、それを使用するすべてのアバターへ影響します。名前、アイコン、ControlType、parameter、value、subMenu、PuppetのsubParametersと方向ラベル・アイコンを設定できます。MA Menu Itemでは同期・値保存・既定項目・自動値割り当ても設定できます。MA Childrenサブメニューでは子構造を保持し、subMenu assetへの置換は行いません。

## MA専用Prefab

通常項目の追加はアバター直下の`ee4v Expression Menu`へ配置したMA専用Prefabを使用します。保存先は対象Prefabと同じディレクトリの`<Prefab名>.ExpressionMenu/ExpressionMenu.prefab`、メニューassetは同フォルダー内です。1つの追加元メニューは8項目までとし、合成メニューへさらに追加する場合は別のMenu Installerを作成します。既存assetのサブメニューへ追加するときは`installTargetMenu`を使用し、MA ChildrenのサブメニューにはMenu Install Targetをその子へ追加して専用Prefab内のInstallerを参照させます。追加後に生成メニューassetの個別表示へ切り替えず、現在のメニュー内で新規項目の設定を表示します。

対象は書き込み可能な通常SceneのAvatar Prefabインスタンスです。元の共有メニューへ項目を直接追加しません。生成フォルダー内のメニューへ追加する場合はそのassetを使用します。生成Prefabは上部item一覧から必ず除外します。AssetManager設定の`assetManager.excludedItemNamePrefixes`は大文字小文字を区別しない名前接頭辞リストで、アバター直下のPrefabを追加除外します。空の既定値では追加除外しません。除外は表示対象の指定で、GameObjectの削除・非アクティブ化は行いません。

## 保存と依存

設定の適用・削除はUndoへ記録します。メニューassetの変更は「メニューassetを保存」で保存し、Scene内MA Componentと生成Prefab配置は既存ホストのAvatar Prefab保存を使用します。生成メニュー追加時は生成assetと専用Prefabを保存します。Scene、Git、DBは機能側で保存しません。AssetManagerのVariant保存と単独WindowのPrefab保存は従来のホストが所有します。

Coreの公開Localization、UI、共有AvatarEditingの編集許可・変更通知・単独Windowに依存します。AvatarEditingを使用する理由は統合版と単独版の対象・保存契約を揃えるためです。他のAvatar機能への参照はありません。VRChat SDK、Modular Avatar runtime、GestureManager runtime / Editorの実際に使うassemblyのみ参照します。GestureManagerへの依存は円形メニューの描画の共用に使用し、Edit Modeの表示・選択でGMのアバター実行モジュールを生成しません。

MAは`src/package.json`の対応範囲（1.18.2以上2.0.0未満）を前提に、内部Editor resolver `VirtualMenu.ForAvatar`、`RootMenuNode`、Childrenのnode key、内部Menu Install Targetへアクセスします。バージョン依存箇所はExpressionMenuModelとExpressionMenuInstallerへ隔離します。resolverが取得できない、解決できない場合はエラーと再読み込みを表示し、不完全な合成メニューへの編集へ代替しません。対応範囲でもMA内部API変更時には確認が必要です。

## 手動確認

「＋」から通常項目と4種類のMAテンプレートを選べること、root・assetサブメニュー・MA Childrenサブメニューへ追加後に新規項目の設定が表示されること、4種類のMAフォームの編集と設定行の追加・削除、出所確認前のMA編集無効、同期・値保存・反転、component削除とUndo、生成項目の削除とUndo、既存Menu Item削除時のObject保持、アバター外・root無効化・同名path・無効スロットの拒否、対象消失の表示、生成Prefabのitem一覧除外を確認します。MAによるビルド後にメニューON/OFFでObject・Material・BlendShapeの状態が切り替わり、無効時に復帰することを確認します。

統合画面と単独Windowで3Dプレビューと説明用HintBoxが表示されず、円形メニューと設定欄が使用可能な横幅へ広がることを確認します。統合画面では表示・編集元の選択欄とメニュー名を表示せず、単独Windowでは編集元を切り替えられること、統合画面で別カテゴリへ移動するとプレビューが再表示されることを確認します。

円周の下端・左右端に短い名前と複数行の名前を置き、通常・選択・拡大中に文字が切れないこと、ポインターを項目と中央円の間で往復させても強調と拡大がちらつかないことを確認します。

隔離Unity 2022.3でDescriptorメニュー、root/指定サブメニューへのMA Installer、MA Childrenサブメニューを含むアバターを使用します。合成表示、階層移動、サブメニューを開いた直後と親への戻る操作後の設定表示、開いているサブメニューの削除・型変更後の親への戻り、最後尾の「＋」によるroot/サブメニューへの追加、追加後の表示元・階層と新規項目の選択、空メニューとページ分割時の「＋」の末尾配置、8項目から9項目へ増えた場合の末尾ページ表示、編集不可時の追加無効、出所確認前の適用・削除無効、確認後の適用・削除とUndo、追加専用Prefabの配置、item一覧の必須除外と設定除外、単独Windowの対象切り替えを確認します。新規自動テストは追加しません。
