# Face Expression

`ee4v/Window/Face Expression/Face Expression Editor`は、VRChatアバター向けの単一フレーム表情クリップを作成します。表情編集、Expression Groups、BlendShape Presetsは`ee4v/Window/Face Expression`へまとめます。標準ハンドジェスチャーへの割り当てと設定は`ee4v/Window/Gesture Assignment`へまとめ、`Gesture Assignments`から独立ウィンドウを開きます。

新規表情クリップの保存ダイアログは、共通アセットルート配下の`Animation/Facial`を既定の保存先として開きます。フォルダーがない場合は作成します。

上部のアバター入力と表情Animation入力は、作成ボタンを除いた横幅を均等に使用します。ウィンドウ幅に応じて両方を同じ割合で縮め、一方だけを0幅にしません。

## 対象範囲

- 名前が`Body`の`SkinnedMeshRenderer`を既定メッシュとしてBlendShapeを列挙する
- グループウィンドウから追加した`SkinnedMeshRenderer`のBlendShapeも同じ表情クリップで編集する
- 有効にしたBlendShapeだけを0秒の単一キーフレームとして`AnimationClip`へ保存する
- 区切り用BlendShapeを編集対象ではないヘッダーとして表示する
- 区切り用BlendShapeからグループを作り、連動ウィンドウから一覧を絞り込む
- 左右それぞれのNeutralと7種類の標準ジェスチャーを組み合わせた64通りへ表情クリップを割り当てる
- 表情ごとにまばたきの有効化と口の動きの固定を設定する
- ジェスチャーへ割り当てた表情をExpression Menuから選択する
- ジェスチャーを使わないメニュー専用表情を追加する
- Modular Avatarを介してFX Controller、Expression Parameters、Expression Menuを合成する

Expression Menu、表情ロック、トリガー量による変化は対象外です。視線の制御は自動生成しません。

## プレビュー

プレビュー開始時にアバターの非表示複製を一度だけ作成します。表情の変更時はAnimatorや`AnimationMode`を動かさず、複製上のBlendShape値だけを更新します。ジェスチャー割り当てで複数のサムネイルを同じ更新内に描画する場合も、スキンメッシュを描画ごとに再計算します。

表情クリップを選択すると、スライダー、数値入力、使用チェックの変更を直ちにプレビューへ反映し、変更内容をRendererパスごとのカーブへ保存します。スライダーまたは数値入力をアバターの初期値へ戻すと使用チェックを自動で外し、対応するカーブを削除します。使用チェックは最初のトグルから縦方向へドラッグすると、最初に切り替えた状態を通過した行へ一括で適用します。ドラッグ中は横位置を判定に使わず、一覧をスクロールした場合も開始行から現在行までを連続して適用します。追加メッシュのBlendShapeも対応するプレビュー複製上のRendererへ適用します。

初期表示とプレビュー右上の表示リセットボタンは同じ処理を使います。Humanoidの頭部を中心にし、顔と肩が収まる距離まで近づけます。頭部を取得できない場合は`Body` Rendererの上部へ合わせ、`Body`も取得できない場合だけアバター全体を収めます。ホイールボタンのドラッグで移動し、右ドラッグで回転します。ホイールで拡大または縮小できます。ウィンドウを閉じるかアバターを変更したときだけ複製を破棄します。

## BlendShape値

各BlendShape行ではスライダーの右に数値入力を表示し、どちらも0～100の範囲で値を編集します。左右トグルは行の右端にR、Lの順で表示します。情報がないトグルは非表示にして配置枠を残し、各操作部の位置と全行のスライダー長を揃えます。複数メッシュを選択した場合は`メッシュ名 / BlendShape名`で表示し、同名Shapeを区別します。

一覧の「BlendShape」見出しは現在のグループ名を表示し、全件表示では「すべて」とします。ベースFBXの保存済みプリセットで、同じ区切り見出しの範囲内にあり`role`が同じ通常、L、RのBlendShapeだけを1行へまとめます。左右以外の末尾表記は役割名の一部として扱うため、番号や括弧表記が異なるBlendShapeは別の行になります。見出しをまたぐ同名の役割も別の行として扱います。`side`が`L`または`R`の場合は左右トグルで対象を切り替え、各BlendShapeの値と使用状態を個別に編集します。プリセットがないFBXや`role`が空の項目は従来どおりBlendShape名を表示します。

「クリップ内のみ」を有効にすると、選択中の表情クリップへ保存されているBlendShapeとそのヘッダーだけを表示します。この状態ではプリセットの対応結果を集約せず、左右指定なし、L、Rの各BlendShapeを実際のBlendShape名による個別行にします。左右指定は操作できないトグルで示します。対応がないBlendShapeも元の名前で表示します。アバターを変更した場合は表情クリップの選択を解除します。

表情クリップを選択するまではBlendShape一覧を表示せず、作成または選択を促す案内を一覧の表示領域へ表示します。

一覧の縦スクロールバーだけを細型で表示し、左右へ余白を確保します。行内のBlendShapeスライダーにはスクロールバー用スタイルを適用しません。

## BlendShapeヘッダー

Preferencesの`4OF/ee4v`設定にある「BlendShapeの区切り文字」で、ヘッダー判定に使う文字列を複数登録できます。この設定はプロジェクト間で共有するユーザー設定で、既定値は`-`、`─`、`=`、`*`です。すべて削除した場合は変換しません。

表情エディタでAvatar Prefabまたはシーン上のPrefabインスタンスを選ぶと、Prefab Variantの対応元を最初のModel Prefabまでたどり、その`.fbx`をベースFBXとして検出します。Rendererの`sharedMesh`は検出に使いません。ベースFBXのプリセットが未登録なら、Chiffon、Kipfel、Shinano、Manukaで使われる末尾の数値、括弧、左右表記を基に大まかな分類を作り、グローバルなプリセット保存先へ自動保存します。既存プリセットは上書きしません。

Preferencesの「FBX別BlendShapeプリセット」には、保存済みプリセットの名前を一覧表示します。「保存先をエクスプローラーで開く」から保存フォルダーを開けます。専用ウィンドウは`ee4v/Window/Face Expression/BlendShape Presets`から開きます。左ペインには区切り見出しごとの役割カード、右ペインには選択した役割に属するBlendShapeと左右指定を表示し、最上部の130px幅の入力欄で役割名を直接編集します。役割カードを別のカードへドラッグすると役割を統合し、右ペインのBlendShapeをドラッグすると個別に所属を変更します。各見出し末尾の「＋」は通常の役割カードと同じNavigation Itemで表示し、ここへドロップすると新規役割を作成します。役割名が空の既存データはBlendShape名ごとの単独カードとして表示し、別のカードへ重ねると所属を設定できます。区切り用BlendShapeは表情エディタと同じ設定で判定し、左ペインの見出しとして扱います。「自動分類」で現在の命名から分類案を作り直せます。保存済み分類を開いただけでは完了メッセージを表示せず、未保存、保存完了、自動分類など操作結果だけを表示します。

プリセットはUser Settingsの「ee4v 共通データの保存先」をルートとし、`preset/blendshape/<FBX名>.json`へグローバルに保存します。各JSONではFBXのGUIDとメッシュのローカルIDへ分類を関連付けます。複数FBX由来のRendererを同時に編集する場合も、それぞれの保存済みプリセットを自動で参照します。表情エディターの更新時にはBlendShape名を解析せず、保存済みの対応表だけを使います。旧プロジェクト設定からの移行は行いません。

例えば区切り文字`-`では、`----------EYE------------`を値を編集するBlendShapeではなく「EYE」ヘッダーとして表示します。`*`も同じ方法で認識します。同じ1文字を繰り返した区切り文字では、左右に指定数以上の連続文字があれば長さが異なっていても認識します。

ヘッダーは表示と検索グループのためだけに使い、表情クリップへの書き込みやプレビューへの適用は行いません。

## グループウィンドウ

`ee4v/Window/Face Expression/Face Expression Editor`を開くと、表情エディターと`Expression Groups`ウィンドウを同時に開きます。グループウィンドウだけを`ee4v/Window/Face Expression/Face Expression Groups`から開くこともできます。

各画面は`ee4v/Debug/Catalog`の`Domain/FaceExpression` Storyで確認できます。`BlendShape Presets` Storyは実際の編集画面をサンプルmappingで表示し、設定を保存しません。`Gesture Assignments` Storyには独立したAssignment Settings画面も含みます。一件分の`GestureAssignmentCell`、`BlendShapePresetMappingRow`、`BlendShapeRow`は画面やGridから分離し、`Domain/FaceExpression/Components` Storyでも確認できます。Toolbar、Preview、見出し、件数表示はCoreの`ActionBar`、`PreviewSurface`、`SectionHeader`、`Badge`を組み合わせます。

BlendShape PresetsのUIは`BlendShapePresetView`へ分離し、`BlendShapePresetWindow`はWindowの生成と実設定への接続を担当します。Storyは同じViewへメモリ上の設定を渡します。

グループウィンドウのGroup見出し横にある「メッシュ追加」から、アバター内にありBlendShapeを持つ`SkinnedMeshRenderer`を追加できます。`Body`は既定で選択されます。追加メッシュはメッシュ名のグループとしてグループ一覧にも表示し、選択するとそのメッシュ内のBlendShapeをすべて表示します。追加メッシュの行を右クリックして「削除」を選ぶと選択対象から外せます。グループ一覧は「Body」と「追加メッシュ」に分けて表示します。アバターを変更した場合は追加メッシュの選択を破棄し、新しいアバターの`Body`だけを選択します。

区切り文字で囲まれた名前をグループ名とし、そのヘッダーから同じメッシュ内の次のヘッダーまでにあるBlendShapeを同じグループとして数えます。グループを選ぶと表情エディターのBlendShape一覧が連動して絞り込まれます。「すべて」を選ぶとグループ外を含む一覧へ戻ります。同名グループが複数のメッシュにある場合は一つにまとめます。

## Modular Avatarへの適用

ジェスチャー割り当ては表情エディターから分離された二つのウィンドウで編集します。メインウィンドウはアバター入力、横並びの「アバターに適用」ボタン、グリッドだけを表示します。行に左手、列に右手のジェスチャーを置いた8×8の表を使います。8列はウィンドウの横幅に合わせて均等に拡大し、セルの縦横比を維持したまま高さも拡大します。最小幅を下回る場合だけ細いスクロールバーで移動できます。各セルは表情クリップの入力欄とアバター表情のサムネイルを兼ね、クリップの選択またはドラッグ＆ドロップで直接割り当てられます。

設定ウィンドウはメインウィンドウと単一セッションを共有します。グリッドで選択した表情のまばたきと口固定を設定ウィンドウで編集します。設定ウィンドウを開いたままUnityを終了した場合は、次回のプロジェクト起動時に保存されたEditorレイアウトから復元します。

「Extra（メニュー限定）」は8×8表と同じスクロール領域の最下段へ組み込み、上端の太線でジェスチャー領域と区切ります。Extraセルも同じ背景色、縦横比、サムネイル兼入力形式です。1行に8個を表示し、追加ボタンを含む9個目以降は左見出し列の後ろから次の行へ送ります。選択中のセルは青枠で表示し、メニュー名、まばたき、口固定、削除操作を設定ウィンドウで編集できます。末尾の背景なし「＋」ボタンから項目を増やせます。「＋」は中央へ大きく表示し、ポインターを重ねたときだけ背景を強調します。グリッド全体のサムネイルはアバターの変更、クリップの割り当て、クリップ内容の編集時だけ再生成します。

適用にはModular Avatarが必要です。アバター直下の`ee4v Face Expressions`オブジェクトへMA Merge Animator、MA Parameters、MA Menu Installer、MA Menu Itemを設定します。Avatar DescriptorのFX Controller、Expression Parameters、Expressions Menuは直接変更しません。NDMFによるアバタービルド時に生成Controllerとメニューを合成します。

生成するAnimator Controllerと正規化クリップは`Assets/ee4v/FaceExpressions`へ保存します。MA Merge Animatorは絶対パス方式でFXレイヤーへ追加します。再適用時はee4vが所有するControllerレイヤー、パラメーター項目、`ee4v Menu `接頭辞のメニュー項目だけを置換し、利用者が追加したオブジェクトやModular Avatar設定を維持します。

表情ごとに使用するBlendShapeカーブの和集合を求め、未指定の値をアバターの既定値で補った生成クリップを作ります。生成クリップも各BlendShapeを0秒の単一キーフレームとして保存します。このためWrite Defaultsを使用せずに表情間の値残りを防ぎます。元の表情クリップは変更しません。

各状態は`GestureLeft`と`GestureRight`の両方が一致した場合だけ再生します。未割り当ての組み合わせではNeutral＋Neutralの設定を使用します。Neutral＋Neutralも割り当てを省略でき、その場合はアバターの既定BlendShape値を使用します。

「まばたきを有効化」した表情では、Avatar Descriptorのまぶた用BlendShapeを生成クリップから除外し、VRChatのまばたきアニメーションを適用します。無効にした表情では同BlendShapeを表情の値またはアバターの既定値へ固定します。

「口の動きを固定」した表情では、Avatar DescriptorのViseme用BlendShapeを表情の値またはアバターの既定値へ固定します。無効にした表情では同BlendShapeを生成クリップから除外し、VRChatのリップシンクを適用します。対象はBlendShape方式のリップシンクです。

ジェスチャーへ割り当てた表情は、クリップとまばたき・口固定の設定が同じものを一つにまとめて`ee4v Expressions`サブメニューへ自動追加します。「メニュー専用表情」には任意の表示名と表情クリップを追加できます。メニュー項目は内部Intパラメーター`ee4v/FaceExpression`を共有し、値0の「Gesture Assignments」でジェスチャー制御へ戻します。Modular Avatarがこのパラメーターを衝突しない名前へ変換し、同期済み・保存対象としてExpression Parametersへ合成します。

以前の単一ジェスチャー割り当てを読み込んだ場合は、従来の左手優先と同じ結果になる64通りの割り当てへ展開します。次回の適用時に新しい形式で保存します。

VRChat SDKへコンパイル時依存は持ちません。Avatar Descriptorとの接続はシリアライズ済みのFXレイヤー境界だけで行い、SDKがない環境でも表情クリップの編集とプレビューは利用できます。

FaceEmoは利用手順と機能範囲を検討する参考にとどめています。データ形式、画面構造、Controller生成方式には依存せず、コードも共有しません。
