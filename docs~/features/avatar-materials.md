# AvatarMaterials

`src/Editor/Feature/Avatar/AvatarMaterials`と`Ee4v.AvatarMaterials.Editor`がMaterialタブの編集処理を所有します。`AvatarMaterialsEditor`は統合ee4vと独立版Materialsの共通実装です。

## 公開境界

`AvatarMaterialsEditor(AvatarEditingContext)`へ対象、選択範囲、Preview、編集可否とホストの通知を渡し、`BuildControls`でUIを生成します。`SelectPreviewMaterial`でPreviewからの選択を受け取ります。Material使用箇所の収集、部位・Prefab範囲の絞り込み、一時的な表示切り替え、割り当ての変更、Inspectorとキャッシュはこの機能が所有します。

初回の部位分類では、骨と未分類の親階層から解決した部位を全Renderer・Material slot間で共有します。分類不能の結果も保持し、同じ骨の名前と親階層を繰り返し調べません。Humanoid対応・骨名・親階層の順で解決する規則は維持します。このキャッシュは機能インスタンスが所有し、`ClearData`と`ResetEditingState`で既存のMaterial分類キャッシュとともに破棄します。

`ReplaceMaterialAssignments`は選択範囲のRendererをUndoに記録し、作業対象の割り当てを変更します。`RefreshAfterMaterialReplacement`が選択・表示とUIを更新します。事前にホストの`FlushChanges`を呼び、体型・パーツの保留変更を確定します。範囲外でも共有されるMaterialの直接編集は`IsMaterialSharedOutsideSelectedPrefab`で拒否します。

編集可能なMaterialかどうか、保護された元素材の扱い、Material Variantを保存するフォルダーと作成処理はホストが決めます。AssetManagerのDB、作業Scene、AssetProtectionには依存しません。他のAvatar機能へのassembly参照もありません。

編集対象の変更では`ResetEditingState`、データの変更では`ClearData`、Prefab構成の変更では`ClearExpandedGroups`を呼びます。`ClearData`は自身のキャッシュとInspectorを解放し、ホストの`InvalidateMaterialData`を呼び返しません。`BuildControls`も再生成前に既存のInspectorを解放します。画面の破棄時は`Dispose`でMaterialEditorを解放します。

`AvatarMaterialsWindow`はこの機能が所有し、共有の`AvatarPrefabEditorWindow`を使用します。Hierarchy上のPrefabインスタンスを入力し、Materialの割り当てはそのインスタンスに変更して、保存ボタンで元Prefabへ適用します。Materialプロパティは割り当て先アセットを直接編集して個別に保存し、通常のUndoで戻せます。「変更を戻す」ボタンと編集開始時のMaterialスナップショットは持ちません。読み取り専用Materialを編集可能にする場合は、元Prefabと同じフォルダーの`<Prefab名>.Materials`へコピーを作成し、対象インスタンスの割り当てを差し替えます。AssetManagerや別Windowを必要とせず、Scene保存やGitの版保存は行いません。

## UI

統合ee4vのMaterial編集は「外見」カテゴリ内の「マテリアル」タブに表示します。独立した外側カテゴリは持たず、パーツ・体型と同じPrefab範囲と部位選択を共有します。Materialタブは一覧と詳細編集を別画面として表示します。詳細対象がないときは一覧だけを表示します。一覧のMaterial名・行とPreviewは、シングルクリックで選択とハイライトを更新し、選択行が閉じたPrefabグループ内にある場合はそのグループを開きます。同じMaterialが複数Prefabで使われる場合も選択表示は共有し、選択したPrefabのグループだけを開きます。一覧では展開後の選択行が画面外や上下端にあるときだけ中央付近へスクロールし、すでに余白を含めて見えている場合は位置を維持します。ダブルクリックでMaterialの詳細へ遷移します。シングルクリックでは画面・Inspector・カメラを変えず、無関係なグループの開閉状態も維持します。詳細表示中に別のMaterialをシングルクリックしても編集対象を維持し、ダブルクリックで切り替えます。統合版・単独Materials Windowともに詳細でも「全身」「手」「足」などの部位切り替え欄を表示し続けます。部位の変更は既存の一覧絞り込みとPreviewのフレーミングへ反映します。統合版では「パーツ」「体型」「マテリアル」の切り替えを表示し続け、その下へ一覧へ戻る操作と選択Materialの編集を配置します。詳細に一覧を併置せず、遷移時は右ペインのスクロールを先頭へ戻します。「一覧へ戻る」で詳細対象とハイライトを解除し、部位切り替え欄を維持したまま、一覧のスクロール位置とPrefabグループの展開状態を復元します。

詳細の見出しにはMaterialの参照欄と使用箇所を表示し、割り当ての差し替えをこの参照欄から行います。編集可能なMaterialではInspector、読み取り専用Materialでは読取専用表示と、Prefabを編集できる場合のMaterial Variant作成ボタンを表示します。Variant作成・差し替え後も置換先の詳細を表示します。一覧の表示切り替えボタンは画面遷移せずPreviewだけを更新します。

詳細ヘッダーの参照欄と使用箇所は縦配置とし、参照欄は残り幅へ縮小し、使用箇所は折り返して右端へはみ出さないようにします。単独表示トグルは薄い背景の操作行へ配置し、左のチェックボックスと右のラベルを縦中央へ揃えます。これらのレイアウト調整はUI Toolkit側だけで行い、ShaderGUIの内部描画設定は変更しません。

一覧またはPreviewでMaterialをダブルクリックして詳細を開くと、選んだPrefab範囲内の使用箇所の部位分類に応じて`FocusBodyPart`を呼び、部位切り替え時と同じカメラ位置・ポーズへ移動します。シングルクリックではカメラを移動しません。腕は部位ボタンと同じ肩・腕グループへまとめます。現在の部位フィルターに属するMaterialはその部位へ、分類先が一部位ならその部位へ、複数部位にまたがる場合や分類不能の場合は全身へフォーカスします。カメラ移動で一覧の部位フィルターを変更せず、一覧へ戻るとフィルターの部位へフォーカスを戻します。

詳細の「他を非表示」は、対象Rootで使用するMaterialのうち選択MaterialだけをPreviewに表示します。既存のMaterial非表示設定を変更せず、オフまたは一覧への復帰で元の表示状態へ戻します。有効なまま編集対象を切り替えたり差し替えたりした場合は、新しい選択Materialだけを表示します。Rendererの割り当てやアセットは変更しません。

`EmbeddedMaterialInspector`は同じ機能内の独立した部品です。MaterialEditorの幅・ラベル幅・変更通知と破棄を管理します。部品のスタイルは`avatar-materials.uss`、共有編集部品は`Feature/Shared/AvatarEditing/avatar-editing.uss`に置きます。

Catalogは`Domain/AvatarMaterials/Containers/AvatarMaterialsEditor`と`Domain/AvatarMaterials/Inputs/EmbeddedMaterialInspector`へ登録します。Storyではメモリー上のサンプルのみ使用し、ProjectのMaterialを保存しません。編集UIの翻訳はAvatarMaterials scopeに置きます。

作業SceneとMaterial Variant保存の接続は[AssetManager](../asset-manager.md)で管理します。
