# I18n

## 機能

I18n は package 内の JSONC 翻訳カタログを読み込み、スコープ単位で文字列を解決します。現在言語、fallback 言語、`en-US` の順で検索します。

## 公開型

| 型 | 役割 |
|---|---|
| `I18N` | 呼び出し元 namespace からスコープを解決する static API |
| `CoreLocalization` | 既定の `ILocalizationService` と再読込イベントを公開する |
| `ILocalizationService` | localizer の取得、言語一覧、再読込を定義する |
| `ILocalizer` | 一つのスコープに対する文字列取得を定義する |
| `ILocalizationCatalogSource` | `LocalizationCatalog` の供給を定義する |
| `ILocalizationLanguageProvider` | 現在言語と fallback 言語の供給を定義する |
| `ILocalizationDiagnostics` | 重複 key の報告先を定義する |
| `LocalizationService` | 上記契約を組み合わせる Unity 非依存実装 |

## `I18N`

| メンバー | 戻り値・動作 |
|---|---|
| `CurrentLanguage` | User Settings の現在言語を返す |
| `FallbackLanguage` | User Settings の fallback 言語を返す |
| `Get(key)` | 翻訳文字列を返す |
| `Get(key, arguments)` | 翻訳文字列を `string.Format` して返す |
| `TryGet(key, out value)` | key を解決できた場合だけ `true` と文字列を返す |
| `GetAvailableLanguages()` | カタログにある locale 名を昇順で返す |
| `Reload()` | 現在のカタログを破棄して再読込を通知する |

`I18N.Get` と `TryGet` は呼び出し元の namespace を確認します。`Ee4v.Sample` と `Ee4v.Sample.Editor` のスコープはいずれも `Sample` です。

明示的なスコープが必要な場合は `CoreLocalization.Current.ForScope(scope)` が返す `ILocalizer` を使います。

## `ILocalizationService`

| メンバー | 戻り値・動作 |
|---|---|
| `Reloaded` | カタログを破棄した後に発生するイベント |
| `ForScope(scope)` | スコープに対応する `ILocalizer` を返す |
| `GetAvailableLanguages()` | 利用可能な locale 名を返す |
| `Reload()` | カタログのキャッシュを破棄する |

`LocalizationService` は作成済みの `ILocalizer` をスコープごとに保持します。カタログは最初に値が必要になった時点で読み込みます。

## カタログ

翻訳ルートは `Editor` 以下にある `Localization` フォルダです。フォルダの親の名前がスコープになります。locale は `xx-YY` 形式の直下フォルダです。各 locale フォルダ直下の `*.jsonc` をファイル名順で読み込みます。

JSONC では行コメント、ブロックコメント、末尾カンマを使用できます。object の入れ子は `.` 区切りの key に展開され、配列は文字列要素を `, ` で連結します。

## 解決規則

1. 現在言語を検索する。
2. 見つからなければ fallback 言語を検索する。
3. 見つからなければ `en-US` を検索する。

同じ locale は一度だけ検索します。key が見つからない場合は key 自体を返します。書式指定に失敗した場合も key 自体を返します。

## 副作用

| 操作 | 副作用 |
|---|---|
| `I18N.CurrentLanguage`、`FallbackLanguage` | Core の言語設定定義を `CoreSettings.Current` へ登録し、値を読む |
| 最初の翻訳参照または言語一覧取得 | package 内の翻訳ファイルを列挙して読み込む |
| カタログ読込 | 検出した重複 key を diagnostics へ渡す。既定 diagnostics は Unity Console へエラーを出す |
| `Reload` | カタログを破棄し、`CoreLocalization.Reloaded` を発生させる |
| `I18N` が再読込を受信 | namespace とスコープのキャッシュを破棄し、Project toolbar と Editor view を再描画する |
| 翻訳アセットの import、削除、移動 | `LocalizationAssetPostprocessor` がカタログを再読込する |
| 言語設定の変更 | Settings の `Changed` を経由してカタログを再読込する |

## 失敗時の動作

| 条件 | 動作 |
|---|---|
| namespace からスコープを解決できない | `Get` は key を返し、呼び出し箇所ごとに一度警告する。`TryGet` は `false` |
| `ForScope` に空のスコープを渡す | `ArgumentException` |
| key がない | `Get` は key を返す。`TryGet` は `false` |
| `string.Format` が失敗 | key を返す |
| JSONC の解析に失敗 | 対象ファイルを読み飛ばし、Unity Console へエラーを出す |
| 同一 locale・スコープで key が重複 | 最初の値を維持し、重複を diagnostics へ渡す |
| catalog source が `null` を返す | 空のカタログとして扱う |
